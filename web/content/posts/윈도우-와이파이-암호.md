윈도우 운영체제를 사용하는 컴퓨터에서 이전에 연결했던 와이파이 암호를 확인하는 것은 간단한 설정을 통해 가능합니다. 비밀번호를 잊어버렸을 때 공유기 초기화 없이도 현재 연결된 네트워크 정보를 불러올 수 있습니다. 보안 설정에 따라 접근 경로가 다를 수 있지만 대개 네트워크 및 인터넷 설정 메뉴에서 해결됩니다. 지금부터 윈도우 환경에서 와이파이 암호를 찾는 구체적인 단계를 설명해 드리겠습니다.

## 네트워크 및 공유 센터 접근

먼저 윈도우 작업 표시줄의 네트워크 아이콘을 우클릭하여 네트워크 및 인터넷 설정 열기를 선택합니다. 창이 뜨면 고급 네트워크 설정 항목 아래에 있는 네트워크 및 공유 센터를 클릭하십시오. 여기서 현재 연결된 와이파이 이름을 확인할 수 있습니다. 연결된 네트워크 이름 옆의 파란색 링크를 누르면 상태 창이 새롭게 나타납니다. 이 상태 창에서 무선 속성 버튼을 찾아 클릭하는 것이 첫 번째 단계입니다.

## 보안 탭에서 암호 표시하기

무선 네트워크 속성 창이 열리면 상단 메뉴 중 보안 탭으로 이동합니다. 보안 탭 내부에는 네트워크 보안 키라는 항목이 있으며 이곳에 암호가 점으로 표시되어 있습니다. 바로 아래에 있는 문자 표시 체크박스를 선택하면 감춰져 있던 와이파이 비밀번호가 그대로 드러납니다. 이제 이 비밀번호를 확인하여 다른 기기에 입력하거나 메모해 두면 됩니다. 보안상 타인에게 노출되지 않도록 주의해야 합니다.

## 명령 프롬프트를 활용한 확인법

설정 메뉴를 거치지 않고 명령 프롬프트를 통해서도 암호를 알 수 있습니다. 윈도우 검색창에 cmd를 입력하여 관리자 권한으로 실행합니다. 이후 netsh wlan show profile 명령어를 입력하면 저장된 와이파이 목록이 뜹니다. 특정 네트워크의 암호를 보려면 netsh wlan show profile name=네트워크이름 key=clear를 입력합니다. 여기서 키 콘텐츠 항목 옆에 적힌 문자가 바로 해당 와이파이의 비밀번호입니다.

## 저장된 프로필 관리와 주의사항

윈도우는 연결했던 모든 와이파이 정보를 프로필 형태로 저장합니다. 만약 더 이상 사용하지 않는 네트워크 정보가 많다면 보안을 위해 삭제하는 것이 좋습니다. 저장된 프로필은 네트워크 설정 내 관리 항목에서 언제든 제거할 수 있습니다. 암호가 노출되면 네트워크를 사용하는 타인에게도 동일한 정보가 공개될 수 있음을 명심하십시오. 공용 PC에서는 이러한 정보를 절대 저장하지 않는 것이 원칙입니다.

## 공유기 관리 페이지 접속

만약 윈도우에서 암호를 찾을 수 없다면 공유기 관리 페이지에 직접 접속해야 합니다. 브라우저 주소창에 공유기 게이트웨이 주소를 입력하여 설정 화면으로 진입하십시오. 로그인 후 무선 설정 메뉴로 들어가면 현재 설정된 와이파이 암호를 직접 변경하거나 확인할 수 있습니다. 공유기 모델마다 주소와 메뉴 구성이 다르므로 매뉴얼을 참고하십시오. 관리자 페이지 비밀번호를 모를 경우 공유기 뒷면의 초기화 버튼을 사용해야 합니다.

## 보안을 위한 주기적인 암호 변경

와이파이 암호를 확인했다면 주기적으로 이를 변경하는 것이 보안상 유리합니다. 기본 비밀번호를 그대로 사용하면 해킹 위험에 노출될 가능성이 큽니다. 영문과 숫자, 특수문자를 조합하여 복잡한 암호를 설정하는 것을 권장합니다. 가족이나 지인에게만 암호를 공유하고 외부인에게는 게스트 네트워크 기능을 활용해 보세요. 네트워크 보안을 강화하는 것은 개인 정보 보호의 가장 기본적인 요소입니다.

윈도우의 네트워크 설정이나 명령 프롬프트를 이용하면 저장된 와이파이 암호를 쉽게 찾을 수 있습니다. 보안을 위해 확인 후에는 주기적으로 비밀번호를 변경하여 안전하게 관리하시기 바랍니다.
