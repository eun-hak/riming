PC 화면 캡처는 키보드 단축키를 이용해 별도의 프로그램 설치 없이 모니터 화면을 이미지로 저장하는 기능입니다. 윈도우 기본 단축키인 윈도우키와 프린트스크린 키를 누르면 전체 화면이 즉시 파일로 저장됩니다. 특정 영역만 지정해서 캡처하거나 지연 시간을 설정하려면 기본 제공되는 캡처 도구를 활용하면 편리합니다.

## 전체 화면을 즉시 파일로 저장하는 단축키

키보드의 윈도우 로고 키와 PrtSc 키를 동시에 누르면 모니터에 보이는 전체 화면이 이미지 파일로 저장됩니다. 이 과정에서 화면이 잠깐 깜빡이며 캡처가 완료되었음을 시각적으로 알려줍니다. 저장된 이미지는 내 PC의 사진 폴더 내 스크린샷 디렉토리에 PNG 형식으로 자동 생성됩니다. 듀얼 모니터를 사용하는 경우 양쪽 화면이 모두 하나의 이미지로 넓게 캡처됩니다.

## 클립보드에 복사하고 문서에 바로 붙여넣기

프린트스크린 단독 키만 누르면 전체 화면이 파일로 저장되지 않고 임시 기억장치인 클립보드에 복사됩니다. 이 상태에서 문서 작성 프로그램이나 메신저 창을 열고 붙여넣기 단축키를 누르면 이미지가 바로 삽입됩니다. 윈도우 10과 11 버전에서는 윈도우키와 V 키를 함께 누르면 그동안 캡처한 이미지 목록을 확인하고 선택해 붙여넣을 수 있습니다.

## 원하는 영역만 잘라서 저장하는 캡처 도구

모니터의 특정 부분만 골라서 저장하고 싶다면 작업표시줄 검색창에 캡처 도구를 입력해 실행합니다. 상단 메뉴에서 새로 만들기를 누른 뒤 마우스 드래그로 원하는 구역을 지정하면 해당 범위만 따로 잘려 나옵니다. 사각형뿐만 아니라 자유형, 창 영역, 전체 화면 등 다양한 형태의 도형 캡처를 지원합니다. 작업이 끝나면 상단 저장 아이콘을 눌러 원하는 폴더에 직접 이름을 지정해 보관할 수 있습니다.

## 활성화된 창만 선택해서 캡처하는 단축키

여러 개의 창이 겹쳐 있는 상태에서 현재 보고 있는 특정 프로그램 창만 깔끔하게 따내고 싶을 때 사용합니다. 알트 키와 프린트스크린 키를 동시에 누르면 현재 활성화된 최상단 창의 영역만 클립보드에 복사됩니다. 주변 배경 화면이나 다른 창은 제외되고 선택된 창의 테두리 안쪽만 깔끔하게 추출되어 문서 자료 제작에 유용합니다. 복사된 이미지는 그림판이나 문서 파일에 바로 붙여넣어 활용할 수 있습니다.

## 지연 시간을 설정해 메뉴 화면 캡처하기

마우스 우클릭 메뉴나 드롭다운 리스트처럼 마우스 커서가 떨어지면 사라지는 화면은 일반적인 방법으로 잡기 어렵습니다. 윈도우 기본 캡처 도구의 새로 만들기 옆에 위치한 지연 시간 설정 메뉴를 활용하면 해결할 수 있습니다. 3초 또는 5초의 시간을 미리 설정한 뒤 캡처를 누르면, 설정된 시간 동안 메뉴를 띄워놓은 상태에서 정지 화면을 얻을 수 있습니다. 게임 화면이나 특정 팝업창 내부의 세밀한 요소를 포착할 때 자주 쓰입니다.

## 웹브라우저 전체 페이지 스크롤 캡처 방법

인터넷 기사나 긴 웹페이지를 한 번에 길게 캡처하려면 브라우저 자체 기능이나 확장 프로그램을 사용해야 합니다. 마이크로소프트 엣지 브라우저는 우측 상단 메뉴에서 웹 캡처 기능을 실행하거나 컨트롤, 시프트, 에스 키를 동시에 눌러 페이지 전체를 길게 저장할 수 있습니다. 크롬 브라우저를 이용하는 경우 스크롤 캡처를 지원하는 서드파티 확장 프로그램을 설치하여 PDF나 이미지 파일로 변환합니다. 웹페이지 길이에 상관없이 하단 끝까지 끊김 없이 하나의 긴 그림 파일로 만들어집니다.
