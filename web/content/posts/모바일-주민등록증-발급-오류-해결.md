## 앱 버전 업데이트 및 캐시 데이터 삭제

가장 먼저 정부24 앱과 PASS 앱이 최신 버전인지 확인해야 합니다. 구버전 앱은 보안 정책 변경으로 인해 인증 연동이 원활하지 않을 수 있습니다. 앱 스토어에서 업데이트를 진행한 뒤 다시 시도해 보시기 바랍니다. 앱 설정 메뉴에서 캐시와 저장 데이터를 삭제하는 것도 효과적인 방법입니다. 데이터가 꼬여 있으면 인증 창이 뜨지 않거나 로딩 중 멈추는 현상이 발생합니다.

## 통신사 본인 확인 서비스 가입 상태 확인

PASS 앱에서 통신사 본인 확인 서비스가 정상적으로 활성화되어 있는지 확인해야 합니다. 간혹 통신사 요금제 변경이나 기기 변경 후 서비스가 해지되는 경우가 있습니다. PASS 앱 내 설정에서 본인 확인 서비스가 활성화 상태인지 체크하십시오. 알뜰폰 사용자의 경우 특정 인증 방식이 제한될 수 있으니 통신사 고객센터에 문의가 필요합니다. 본인 명의의 휴대폰이 아니라면 서비스 이용이 불가능합니다.

## 네트워크 및 보안 설정 점검하기

Wi-Fi 환경보다는 LTE나 5G 데이터 환경에서 인증을 진행하는 것이 더 안정적입니다. 일부 공공 와이파이는 보안 정책상 인증 서버 접속을 차단할 수 있습니다. 스마트폰의 시간 설정이 자동 모드가 아닌 경우에도 인증 실패가 발생할 수 있습니다. 기기 설정에서 시간과 날짜를 표준시 자동 설정으로 변경해 보시기 바랍니다. 또한 VPN 앱이 켜져 있다면 잠시 종료하고 다시 시도하십시오.

스마트폰이 루팅되었거나 커스텀 롬이 설치된 경우 보안 앱 인증이 거부됩니다. 모바일 주민등록증은 금융권 수준의 보안을 요구하므로 기기 무결성을 체크합니다. 순정 상태의 스마트폰을 사용하는지 다시 한번 확인하십시오. 또한 보안 폴더를 사용 중이라면 보안 폴더 외부에서 인증을 시도하는 것이 권장됩니다. 기기 자체의 보안 설정이 너무 높으면 앱 접근 권한이 제한될 수 있습니다.
