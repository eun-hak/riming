LG 그램 노트북을 사용하다 갑자기 와이파이 연결이 안 되거나 네트워크 아이콘에 노란 뜀표가 뜰 때가 있습니다. 결론부터 말씀드리면 공유기 오류부터 윈도우 네트워크 어댑터 드라이버 충돌까지 원인이 다양하므로 순서대로 점검해야 합니다. 무작정 서비스센터에 가기 전에 집에서 간단히 시도해 볼 수 있는 소프트웨어적 해결 방법들이 존재합니다. 그램 무선 인터넷 오류를 잡는 구체적인 조치 요령을 안내합니다.

## 노트북 비행기 모드와 무선 랜카드 물리적 상태

가장 먼저 확인해야 할 부분은 키보드 단축키나 설정으로 인해 비행기 모드가 켜져 있는지 여부입니다. fn 키와 F번 키 조합으로 와이파이 기능 자체가 꺼져 있는 경우가 생각외로 자주 발생합니다. 또한 외장 무선 랜카드가 장착된 모델이라면 헐겁게 연결되었는지 확인할 필요가 있습니다. 간단한 토글 스위치 조작만으로도 인터넷이 곧바로 살아나는 경우가 많습니다.

## 공유기와 모뎀 전원 재부팅을 통한 네트워크 초기화

노트북 자체의 문제라기보다는 가정 내 인터넷을 뿌려주는 공유기나 모뎀의 일시적 오류일 확률이 높습니다. 공유기 전원 콘센트를 뽑고 약 1분 정도 기다린 후 다시 꽂아 네트워크를 재부팅해 봅니다. 이 과정만으로도 IP 충돌이나 내부 메모리 과부하로 인한 연결 끊김 현상이 깨끗하게 해결됩니다. 스마트폰 등 다른 기기에서도 와이파이가 안 된다면 확실히 공유기 문제입니다.

## 장치 관리자에서 무선 랜카드 드라이버 재설치

윈도우 시스템 내부의 무선 네트워크 어댑터 드라이버가 손상되었거나 꼬였을 때 연결이 차단됩니다. 시작 버튼을 우클릭하여 장치 관리자에 들어간 뒤 네트워크 어댑터 항목을 펼쳐줍니다. 인텔 등의 무선 랜 장치를 우클릭하여 디바이스 제거를 누른 후 노트북을 재부팅하면 자동으로 다시 설치됩니다. 이 방법은 와이파이 메뉴가 아예 사라졌을 때 매우 효과적인 대처법입니다.

## 네트워크 명령 프롬프트를 이용한 IP 설정 초기화

와이파이는 잡혔는데 인터넷 연결이 안 되거나 IP 주소를 받아오지 못하는 오류가 발생할 수 있습니다. 작업표시줄 검색창에 cmd를 입력하여 명령 프롬프트를 관리자 권한으로 실행합니다. ipconfig release 명령어와 ipconfig renew 명령어를 차례로 입력해 IP 정보를 새로 갱신합니다. 이어서 netsh int ip reset 명령을 넣어 TCP IP 스택을 공장 초기화합니다.

## LG Update 프로그램을 통한 최신 드라이버 갱신

윈도우 업데이트 과정에서 기존 무선 드라이버와 충돌이 일어나 와이파이가 먹통이 되기도 합니다. 엘지 그램에 기본 탑재된 LG Update 프로그램을 실행하여 최신 무선 랜 드라이버가 있는지 확인합니다. 만약 유선 인터넷 연결이 아예 불가능하다면 스마트폰 테더링이나 USB 랜카드를 활용해 드라이버를 다운받아야 합니다. 제조사가 배포하는 최신 안정화 버전을 설치하는 것이 가장 근본적인 해결책입니다.

## 윈도우 네트워크 및 인터넷 문제 해결사 실행

마이크로소프트 윈도우 시스템 자체에 내장된 진단 도구를 활용하는 것도 좋은 방법입니다. 설정의 네트워크 및 인터넷 메뉴로 들어가 문제 해결 버튼을 클릭합니다. 윈도우가 스스로 어댑터 상태를 검사하고 발견된 오류를 자동으로 수정 작업을 거칩니다. 사용자가 직접 원인을 찾기 힘들 때 유용한 일종의 자동 진단 네비게이션입니다.

그램 와이파이 오류는 대부분 공유기 재부팅이나 무선 랜 드라이버 재설치 과정을 통해 정상적으로 복구됩니다. 차근차근 단계를 밟아 문제를 해결해 보시기 바랍니다.
