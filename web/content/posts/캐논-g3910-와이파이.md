가정이나 소규모 사무실에서 널리 쓰이는 캐논 무한잉크 복합기 G3910은 무선 와이파이 연결을 지원합니다. 스마트폰이나 노트북에서 선을 꽂지 않고 무선으로 자유롭게 문서를 출력할 수 있어 매우 편리합니다. 처음 프린터를 구매했거나 공유기를 교체했을 때 와이파이 설정을 올바르게 거쳐야 무선 출력이 가능합니다.

## 프린터 본체 조작부에서 Wi-Fi 버튼 활성화

캐논 G3910 프린터 전원을 켠 후 조작부에 있는 무선 다이렉트 버튼이나 Wi-Fi 버튼을 누릅니다. 액정 화면과 상태 표시등에 와이파이 설정 모드가 활성화되었음을 알리는 불빛이 깜빡입니다. WPS 기능을 지원하는 공유기를 사용 중이라면 공유기의 WPS 버튼을 누른 후 프린터 버튼을 눌러 간편하게 연결합니다. 일반적인 경우 무선 라우터 설정 모드로 진입하여 네트워크를 탐색합니다.

## 캐논 공식 드라이버 및 유틸리티 소프트웨어 설치

스마트폰이나 컴퓨터에서 프린터를 무선으로 인식하려면 전용 드라이버와 소프트웨어가 필요합니다. 컴퓨터의 인터넷 브라우저를 켜고 캐논 공식 홈페이지 고객지원 다운로드 센터로 이동합니다. G3910 모델명을 정확히 입력한 후 운영체제에 맞는 최신 드라이버 설치 파일을 내려받습니다. 설치 프로그램 실행 도중 무선 LAN 연결 방식을 선택하고 안내에 따릅니다.

## 스마트폰 Canon PRINT 앱 활용 무선 연결

PC 없이 스마트폰에서 곧바로 문서를 무선 인쇄하려면 전용 모바일 앱을 다운로드해야 합니다. 앱스토어나 플레이스토어에서 Canon PRINT Inkjet SELPHY 앱을 검색하여 설치합니다. 스마트폰이 집안의 2.4GHz 와이파이에 연결된 상태에서 앱을 실행하고 프린터 추가를 진행합니다. 프린터와 스마트폰이 동일한 무선 네트워크 대역에 있어야 인식이 원활합니다.

## 2.4GHz와 5GHz 주파수 대역 확인 사항

캐논 G3910 복합기는 5GHz 와이파이 신호를 지원하지 않고 2.4GHz 대역의 주파수만 인식합니다. 공유기 설정이 5GHz로만 고정되어 있거나 공유기 이름이 혼동되면 프린터가 와이파이를 찾지 못합니다. 스마트폰이나 노트북을 2.4GHz 와이파이에 연결한 상태에서 프린터 세팅을 진행해야 오류가 안 납니다. 공유기 관리자 페이지에서 두 주파수의 이름을 분리하여 세팅하는 것이 안전합니다.

## 프린터 네트워크 설정 초기화 방법

이전에 다른 공유기에 연결되었던 이력이 있거나 와이파이가 자꾸 끊기면 네트워크를 초기화해야 합니다. 프린터 조작부의 중지 버튼을 누르고 있는 상태에서 Wi-Fi 버튼을 반복해서 눌러 초기화합니다. 액정 화면의 무선 랜 불빛이 꺼지고 설정이 리셋되면 처음부터 다시 연결을 시도합니다. 프린터의 임시 메모리를 비워주는 과정으로 연결 오류를 효과적으로 해결합니다.

## 방화벽 차단 해제 및 인쇄 스풀러 점검

프린터와 컴퓨터가 모두 와이파이에 연결되었음에도 인쇄 명령이 내려가지 않을 때 조치합니다. 윈도우 방화벽이나 설치된 백신 프로그램이 캐논 프린터의 네트워크 통신을 차단하고 있는지 확인합니다. 제어판의 장치 및 프린터 메뉴에서 G3910 아이콘을 마우스 우클릭하여 인쇄 작업 목록을 비웁니다. 인쇄 스풀러 서비스를 재시작하여 대기 중인 문서 오류를 해결합니다.

캐논 G3910 와이파이 연결은 2.4GHz 주파수 확인과 전용 드라이버 설치가 핵심입니다. 정상 인쇄를 확인하세요.
