컴퓨터로 중요한 작업을 하던 중 갑자기 인터넷 연결이 끊기면 당황스럽고 난감해집니다. 웹서핑이 되지 않을 때 공유기 문제인지, 랜선 불량인지, 아니면 윈도우 네트워크 설정 오류인지 차근차근 확인해야 합니다. 전문가를 부르기 전에 집에서 직접 시도해 볼 수 있는 점검 방법들이 다양하게 존재합니다. 지금부터 컴퓨터 인터넷이 안 될 때 원인을 찾고 복구하는 구체적인 과정을 안내해 드립니다.

## 랜선 연결 상태와 포트 확인

데스크톱 본체 뒤쪽에 꽂혀 있는 인터넷 랜선이 헐거워졌는지 가장 먼저 확인합니다. 랜선 단자가 빠져 있거나 딸깍 소리가 나도록 단단히 고정되지 않으면 신호가 끊깁니다. 본체 뒤편 랜카드 포트에 불이 들어오는지 살펴보고,선이 끊어진 곳은 없는지 살펴봅니다. 다른 랜선으로 교체해 보았을 때 정상 작동한다면 케이블 단선 불량으로 판단합니다.

## 인터넷 공유기 및 모뎀 재부팅

컴퓨터 본체뿐만 아니라 거실에 있는 메인 모뎀과 공유기 전원을 재부팅해야 합니다. 공유기 전원 플러그를 뽑았다가 10초 후에 다시 꽂아 통신 장비의 시스템을 초기화합니다. 통신사 장비가 재부팅되면서 IP를 다시 할당받는 과정에서 인터넷이 복구되는 경우가 많습니다. 공유기 LED 불빛이 모두 정상적으로 켜지는지 반드시 확인합니다.

## 윈도우 네트워크 문제 해결사 실행

작업표시줄 오른쪽 아래의 네트워크 아이콘을 마우스 우클릭하여 문제 해결을 선택합니다. 윈도우 시스템이 자동으로 랜카드와 드라이버, IP 설정을 진단하고 오류를 바로잡습니다. 진단 과정에서 발견된 문제를 사용자가 직접 수정할 수 있도록 안내 문구가 나타납니다. 이 기능만으로도 일시적인 네트워크 드라이버 충돌 문제는 대부분 해결됩니다.

## 네트워크 어댑터 사용 안 함 및 재활용

제어판의 네트워크 및 공유 센터에서 어댑터 설정 변경 메뉴로 이동합니다. 현재 사용 중인 이더넷 랜카드 아이콘을 마우스 우클릭하여 사용 안 함으로 바꿉니다. 5초 정도 기다린 후에 다시 우클릭하여 사용으로 변경하여 랜카드를 강제로 재시작합니다. 이 방법은 랜카드가 일시적으로 멈춰버린 현상을 깔끔하게 풀어주는 효과가 있습니다.

## 명령 프롬프트에서 IP 주소 갱신

윈도우 시작 버튼을 누르고 검색창에 cmd를 입력하여 명령 프롬프트를 관리자 권한으로 엽니다. 검은색 창이 뜨면 ipconfig /release를 입력하여 기존 IP 주소를 해제합니다. 이어서 ipconfig /renew를 입력하여 새로운 IP 주소를 공유기에서 다시 받아옵니다. 마지막으로 ipconfig /flushdns를 입력해 DNS 캐시를 깨끗하게 비워줍니다.

## 랜카드 드라이버 재설치 및 점검

장치 관리자에서 네트워크 어댑터 항목을 열어 랜카드 드라이버에 노란색 느낌표가 있는지 봅니다. 드라이버 오류가 발생했다면 제조사 홈페이지에서 최신 드라이버를 다운받아 재설치합니다. 본체 메인보드의 랜카드 하드웨어 고장일 경우 외장 USB 랜카드를 장착해 해결할 수 있습니다.

컴퓨터 인터넷 연결 오류는 랜선 점검과 네트워크 초기화로 대부분 스스로 해결할 수 있습니다. 순서대로 점검하여 답답한 인터넷 문제를 시원하게 해결하시길 바랍니다.
