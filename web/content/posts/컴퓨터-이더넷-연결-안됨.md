컴퓨터에서 유선 인터넷인 이더넷 연결이 갑자기 먹통이 되어 당황스러운 경험을 하신 적이 있으실 겁니다. 랜선 불량이나 네트워크 카드 드라이버 오류 또는 공유기 문제 등 원인은 매우 다양하게 존재합니다. 유선 연결이 안 될 때 임시로 와이파이를 활용해 인터넷을 유지하면서 근본적인 원인을 찾아 해결해야 합니다. 컴퓨터 이더넷 오류를 신속하게 해결하는 구체적인 요령을 안내해 드립니다.

## 랜선 및 공유기 물리적 연결 상태 점검

가장 먼저 컴퓨터 뒷면의 랜포트와 벽면 단자 또는 공유기에 연결된 랜선이 헐거워지지 않았는지 확인합니다. 랜선을 뽑았다가 딸깍 소리가 나도록 다시 정확하게 꽂아 물리적인 접촉 불량을 해소합니다. 가정 내 공유기 전원 플러그를 뽑았다가 약 10초 후에 다시 꽂아 네트워크 장비를 재부팅합니다. 공유기의 랜선 포트 위치를 다른 구멍으로 바꿔보는 것도 일시적인 통신 오류를 잡는 좋은 방법입니다.

## 네트워크 어댑터 사용 안 함 상태 확인

실수로 키보드 단축키를 누르거나 시스템 오류로 인해 이더넷 어댑터 자체가 비활성화된 경우가 종종 있습니다. 윈도우 제어판의 네트워크 및 공유 센터로 들어가 어댑터 설정 변경 메뉴를 실행합니다. 이더넷 아이콘이 회색빛으로 흐리게 변해 있다면 마우스 우클릭을 눌러 사용 설정으로 바꿔줍니다. 이 간단한 조작만으로도 끊겼던 유선 인터넷 신호가 즉시 살아나는 경우가 매우 많습니다.

## 랜카드 드라이버 재설치 및 업데이트

메인보드 랜카드 드라이버가 손상되었거나 최신 윈도우 업데이트와 충돌을 일으키면 이더넷이 인식되지 않습니다. 윈도우 시작 버튼을 우클릭하여 장치 관리자를 실행한 뒤 네트워크 어댑터 목록을 펼칩니다. 본인의 랜카드 장치 이름을 찾아 우클릭한 후 디바이스 제거를 선택하고 컴퓨터를 재부팅합니다. 재부팅 과정에서 윈도우가 드라이버를 자동으로 다시 설치하며 정상적인 작동을 유도합니다.

## 명령 프롬프트 IP 주소 초기화 작업

컴퓨터의 IP 주소 설정이 꼬였거나 네트워크 캐시가 쌓인 경우 명령어를 통해 깨끗하게 초기화할 수 있습니다. 윈도우 검색창에 cmd를 입력하여 명령 프롬프트를 관리자 권한으로 실행합니다. 검은색 창에 ipconfig /release를 입력해 기존 설정을 비우고 이어 ipconfig /renew를 입력해 새로고침합니다. 마지막으로 netsh winsock reset 명령어를 치고 컴퓨터를 다시 시작하면 네트워크 환경이 정비됩니다.

## 임시 방편으로 와이파이 무선 연결 활용

유선 이더넷 수리가 바로 어렵거나 급한 업무를 처리해야 할 때는 와이파이 동글이나 무선 랜카드를 활용합니다. 메인보드에 무선 기능이 내장되어 있다면 주변 와이파이에 접속하여 임시로 인터넷을 사용할 수 있습니다. USB 형태의 무선 랜카드를 컴퓨터에 장착하면 유선 랜포트 고장 상황에서도 원활한 웹서핑이 가능해집니다. 근본적인 유선 수리를 진행하는 동안 임시 대안으로 매우 유용한 방법입니다.

## 메인보드 랜포트 하드웨어 고장 진단

소프트웨어적 조치와 랜선 교체에도 불구하고 이더넷 포트에 불이 전혀 들어오지 않는다면 하드웨어 고장입니다. 메인보드에 부착된 랜카드 칩셋 자체의 수명이 다했거나 낙뢰 등으로 인해 포트가 손상된 경우입니다. 이럴 때는 시중에 판매되는 외장형 랜카드를 USB나 PCI 슬롯에 장착하여 저렴하게 수리할 수 있습니다. 자가 수리가 어렵다면 전문 컴퓨터 수리 업체를 통해 정확한 진단을 받아보시기 바랍니다.

컴퓨터 이더넷 연결 오류는 랜선 점검과 네트워크 어댑터 설정을 통해 대부분 해결됩니다. 유선이 안 될 때는 무선 와이파이를 임시로 활용해 보세요.
