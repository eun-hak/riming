하드디스크를 컴퓨터에 연결하는 작업은 물리적 연결과 소프트웨어 설정이라는 두 단계로 나뉩니다. 외장 하드라면 USB 케이블을 통해 쉽게 연결되지만, 내장 하드나 새로운 드라이브를 추가할 때는 설정이 필요할 수 있습니다. 운영체제에서 하드디스크가 제대로 인식되지 않을 때 확인해야 할 점검 사항을 중심으로 설명합니다.

## 외장 하드 물리적 연결 순서

외장 하드디스크는 제공된 전용 케이블을 사용하여 컴퓨터의 USB 포트에 연결합니다. 데스크탑의 경우 본체 뒷면의 메인보드 USB 포트에 직접 연결하는 것이 전력 공급 측면에서 더 안정적입니다. 케이블이 헐겁지 않은지 확인하고, 하드디스크의 LED 표시등이 점등되는지 확인합니다. 만약 인식이 되지 않는다면 다른 USB 포트에 꽂아보며 반응을 살핍니다. 허브를 사용할 경우 전력 부족으로 인식이 제한될 가능성이 큽니다.

## 내장 하드디스크 직접 장착 방법

PC 본체를 열고 SATA 케이블과 전원 케이블을 각각 메인보드와 하드디스크에 연결합니다. 데이터 전송을 위한 SATA 데이터 케이블은 메인보드의 SATA 포트에, 전원 케이블은 파워서플라이에서 나오는 단자에 꽂습니다. 장착 후 나사로 고정하여 진동을 방지해야 합니다. 부팅 후 바이오스 화면에서 하드디스크가 하드웨어 목록에 올라와 있는지 확인하는 과정이 선행됩니다.

## 디스크 관리 도구 활용하기

장착은 완료되었으나 내 컴퓨터에서 드라이브가 보이지 않는다면 윈도우의 디스크 관리 기능을 실행합니다. 윈도우 키와 X를 누른 뒤 디스크 관리를 선택하여 새 디스크가 할당되지 않음 상태인지 확인합니다. 해당 디스크를 마우스 오른쪽 버튼으로 클릭하여 초기화를 진행합니다. 초기화 후 검은색으로 표시된 할당되지 않은 영역을 우클릭하여 새 단순 볼륨을 생성합니다.

## 드라이브 문자 할당 및 포맷 설정

단순 볼륨 만들기 마법사를 실행하면 드라이브 문자를 할당하고 파일 시스템을 지정합니다. 일반적인 윈도우 환경에서는 NTFS 형식을 선택하는 것이 권장됩니다. 빠른 포맷에 체크하고 마침을 누르면 드라이브가 즉시 활성화됩니다. 이 과정에서 기존 데이터는 삭제되므로 새 하드디스크인지 확인이 필요합니다. 완료 후 내 PC에서 새로운 드라이브가 정상적으로 나타나는지 확인합니다.

## 인식이 안 될 때 해결 방안

하드디스크가 연결되었음에도 작동하지 않는다면 드라이버 업데이트를 시도합니다. 장치 관리자에서 디스크 드라이브 항목을 찾아 해당 장치의 드라이버를 업데이트하거나 제거 후 재설치합니다. 케이블 불량일 가능성도 있으므로 다른 기기에서 테스트해 보는 것도 방법입니다. 전원 공급이 원활하지 않아 소음만 나고 회전하지 않는다면 하드디스크 자체의 고장 가능성을 고려해야 합니다.

## 안전하게 하드디스크 제거하기

데이터 손상을 방지하기 위해 외장 하드를 분리할 때는 반드시 소프트웨어적 절차를 거칩니다. 윈도우 작업 표시줄 오른쪽 하단의 하드웨어 안전하게 제거 아이콘을 클릭합니다. 현재 사용 중인 드라이브를 선택하여 중지 메시지가 뜰 때까지 기다립니다. 이후 물리적으로 케이블을 뽑아야 파일 시스템 오류를 방지할 수 있습니다. 급하게 케이블을 제거하면 데이터 쓰기 오류가 발생할 위험이 있습니다.

하드디스크 연결은 물리적 장착 후 디스크 관리에서 볼륨을 생성해야 완료됩니다. 인식 오류 시에는 케이블 확인과 장치 관리자 설정을 순차적으로 점검하십시오.
