와이파이에 연결된 기기가 목록에 나타나지 않도록 숨기거나 관리하는 방법은 보안과 프라이버시 유지에 매우 유용합니다. 공유기 관리자 페이지에 접속하여 SSID 숨기기 기능을 설정하면 주변 기기에서 해당 와이파이 이름이 검색되지 않도록 만들 수 있습니다. 또한 불필요하게 연결된 특정 기기를 차단하거나 맥 어드레스 필터링을 활용하는 것도 좋은 대안입니다. 와이파이 연결 기기 노출을 방지하기 위한 구체적인 설정 절차를 안내해 드리겠습니다.

## 공유기 관리자 페이지 접속하기

공유기에 연결된 컴퓨터나 스마트폰의 브라우저 주소창에 게이트웨이 주소를 입력하여 관리자 페이지에 접속합니다. 통신사별 혹은 공유기 제조사별로 기본 IP 주소가 다르므로 기기 하단의 스티커를 참고해야 합니다. 초기 아이디와 비밀번호를 입력하여 로그인을 완료합니다. 로그인 후 무선 설정 또는 네트워크 관리 메뉴로 이동합니다.

## SSID 이름 숨기기 설정 방법

무선 네트워크 설정 메뉴에서 SSID 브로드캐스트 끄기 또는 이름 숨기기 항목을 체크합니다. 이 기능을 활성화하면 스마트폰이나 노트북의 기본 와이파이 검색 목록에 해당 공유기가 나타나지 않습니다. 이미 연결된 적이 있는 기기는 자동으로 접속되지만 처음 연결하는 기기는 네트워크 이름을 직접 입력해야 합니다. 무단 접속을 차단하는 기본적인 보안 강화 방법 중 하나입니다.

## 연결된 기기 목록 확인 및 관리

관리자 페이지의 장치 연결 상태 또는 DHCP 클라이언트 정보 메뉴에서 현재 접속 중인 모든 기기를 볼 수 있습니다. 스마트폰, TV, 가전제품 등 각 기기의 IP 주소와 맥 어드레스가 표시됩니다. 모르는 기기가 접속해 있다면 네트워크 보안에 취약해진 상태이므로 즉시 조치를 취해야 합니다. 정기적으로 이 목록을 확인하는 습관이 중요합니다.

## 원치 않는 기기 차단 설정하기

접속 목록에서 차단하고자 하는 기기를 선택하여 접근 거부 설정을 적용할 수 있습니다. 제조사 공유기 프로그램에 따라 기기별로 인터넷 차단 버튼을 제공하는 경우도 있습니다. 차단된 기기는 와이파이 신호는 잡히지만 인터넷 데이터 통신을 할 수 없게 됩니다. 가족 외의 외부 기기나 알 수 없는 기기가 잡혔을 때 유용한 기능입니다.

## 맥 어드레스 필터링 활용하기

허용된 특정 기기만 와이파이를 쓸 수 있도록 맥 어드레스 인증 방식을 설정할 수 있습니다. 공유기 보안 설정에서 허용 목록에 등록된 기기의 고유 번호만 통신을 허용하도록 지정합니다. 이 설정을 완료하면 등록되지 않은 새로운 기기는 비밀번호를 알아도 접속할 수 없습니다. 설정 과정이 다소 번거로울 수 있으나 보안 수준을 극대화할 수 있습니다.

## 와이파이 비밀번호 변경으로 일괄 차단

현재 연결된 모든 기기를 한 번에 차단하고 싶다면 와이파이 비밀번호를 변경하는 것이 가장 확실합니다. 무선 보안 설정 메뉴에서 암호 키를 새로운 조합으로 수정하고 저장합니다. 비밀번호가 변경되면 기존에 연결되어 있던 모든 기기의 접속이 자동으로 해제됩니다. 이후 필요한 기기들에만 새로운 비밀번호를 다시 입력해 줍니다.

와이파이 기기 노출을 막으려면 공유기 관리자 페이지를 통한 SSID 숨기기와 비밀번호 변경이 효과적입니다. 주기적으로 연결 기기를 점검하여 보안을 유지하시기 바랍니다.
