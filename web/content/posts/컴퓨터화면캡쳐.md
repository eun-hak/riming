컴퓨터 화면 캡처는 윈도우 운영체제에서 제공하는 단축키와 기본 도구를 활용하면 별도의 프로그램 설치 없이 즉시 실행할 수 있습니다. 키보드 자판 조합 하나로 전체 화면부터 특정 영역까지 자유롭게 저장하는 방식이 가장 널리 쓰입니다. 작업 목적에 맞는 캡처 수단을 선택하면 업무 효율을 높이고 필요한 이미지를 손쉽게 확보할 수 있습니다. 윈도우 기본 기능부터 세부적인 활용 방법을 정리해 드립니다.

## 전체 화면을 한 번에 저장하는 윈도우 단축키

키보드의 윈도우 로고 키와 PrtSc(프린트 스크린) 키를 동시에 누르면 모니터에 보이는 전체 화면이 즉시 이미지 파일로 저장됩니다. 저장된 파일은 내 PC의 사진 폴더 내 스크린샷 디렉토리에서 자동으로 확인할 수 있습니다. 별도의 편집 프로그램에 붙여넣는 과정이 생략되므로 연속적인 캡처가 필요할 때 매우 유용합니다. 듀얼 모니터를 사용하는 환경에서는 양쪽 화면이 모두 하나의 이미지로 캡처됩니다.

## 원하는 영역만 잘라내는 캡처 도구 단축키

키보드에서 윈도우 로고 키와 Shift 키, 그리고 S 키를 동시에 누르면 화면 상단에 캡처 바가 나타납니다. 사각형, 자유형, 창, 전체 화면 중 원하는 형태를 마우스로 드래그하여 선택할 수 있습니다. 영역을 지정하는 순간 클립보드에 임시 저장되며 알림창을 눌러 편집 및 저장 작업을 수행합니다. 전체 화면에서 특정 부분만 빠르게 추출해야 할 때 가장 자주 활용되는 기능입니다.

## 클립보드에만 임시로 담아 붙여넣는 방식

PrtSc 키만 단독으로 누르면 모니터 화면 전체가 클립보드에 복사되고 파일로는 바로 저장되지 않습니다. 이 상태에서 문서 작성 프로그램이나 그림판을 열고 Ctrl과 V 키를 누르면 이미지가 나타납니다. 문서 작업 중 특정 화면을 잠시 가져와서 보여줄 때 유용한 방식입니다. 단축키 한 번으로 저장 파일이 늘어나지 않아 임시 작업에 적합합니다.

## 마우스 포인터까지 포함해 캡처하는 설정

윈도우 기본 캡처 도구의 설정 메뉴를 열면 마우스 커서를 이미지에 포함시킬지 여부를 선택할 수 있습니다. 매뉴얼 제작이나 오류 화면 공유 시 마우스 포인터의 위치를 함께 보여줘야 할 때 유용합니다. 설정에서 지연 시간을 몇 초 부여하면 팝업 메뉴가 열린 상태 그대로 캡처할 수 있습니다. 화면을 띄운 채 마우스를 움직여야 하는 상황에서 필수적인 옵션입니다.

## 인터넷 창 전체를 길게 스크롤하며 담는 방법

웹페이지의 끝까지 한 번에 캡처하려면 브라우저 확장 프로그램이나 별도의 웹 스크린샷 도구를 이용해야 합니다. 윈도우 기본 기능만으로는 긴 웹문서의 하단 영역까지 자동으로 스크롤하여 담기 어렵습니다. 브라우저 설정 메뉴나 스토어에서 화면 전체 캡처 기능을 지원하는 유틸리티를 설치하여 실행합니다. 긴 기사나 레포트 자료를 이미지로 보관할 때 주로 사용됩니다.

## 저장된 이미지 파일의 기본 경로와 변경 방법

윈도우 단축키로 생성된 스크린샷 파일은 기본적으로 사용자의 사진 폴더 내 스크린샷 하위 디렉토리에 쌓입니다. 이 저장 위치를 바꾸고 싶다면 사진 폴더의 속성 메뉴에서 위치 탭을 눌러 다른 드라이브나 경로로 지정하면 됩니다. C드라이브 용량이 부족할 때 저장 경로를 외부 저장소나 다른 파티션으로 분산시키는 효과가 있습니다. 경로를 변경한 이후에도 단축키 동작 방식은 동일하게 유지됩니다.

컴퓨터 화면 캡처는 목적에 맞춰 윈도우 단축키와 기본 도구를 조합하면 빠르고 편리하게 처리할 수 있습니다. 별도의 유틸리티 설치 없이도 대부분의 업무와 일상적인 저장이 가능합니다.
