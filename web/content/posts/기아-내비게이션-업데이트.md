기아 차량의 지도와 시스템을 최신 버전으로 갱신하려면 공식 홈페이지에서 제공하는 전용 프로그램을 설치해야 합니다. PC나 노트북에 프로그램을 내려받은 뒤 회원 로그인 또는 차량 본인 인증 과정을 거칩니다. 인증이 완료되면 보유하고 있는 차량 모델명이 자동으로 인식되거나 직접 선택할 수 있는 화면이 나타납니다. 해당 프로그램은 대용량 파일 다운로드를 지원하므로 안정적인 유선 인터넷 환경에서 실행하는 것이 효율적입니다.

내비게이션 파일을 담아 차량으로 옮길 이동식 저장장치가 필수적으로 요구됩니다. 일반적인 USB 메모리는 최소 32기가바이트 이상의 여유 공간이 확보된 제품을 권장합니다. 저장장치 내부에 기존에 있던 다른 파일이 존재할 경우 오류가 발생할 수 있으므로 포맷을 진행한 후 사용하는 것이 안전합니다. 파일 시스템 형식은 프로그램 안내에 맞춰 설정해야 차량 단말기에서 원활하게 인식됩니다.
