캐논 프린터를 무선 네트워크에 연결하여 스마트폰이나 노트북에서 간편하게 문서를 출력하는 방법을 안내합니다. 드라이버 설치 과정에서 무선 연결을 설정하거나 프린터 본체 패널을 통해 직접 공유기를 잡는 방식이 있습니다. 기종별 차이가 있을 수 있으므로 제조사 공식 매뉴얼을 참고하여 진행합니다.

## 무선 연결 전 사전 준비 사항

공유기의 전원이 켜져 있고 스마트폰이나 PC가 동일한 와이파이 주파수에 접속되어 있는지 확인합니다. 캐논 프린터 본체의 무선 램프가 깜빡이거나 켜져 있는지 살펴봅니다. 5GHz 대역만 지원하는 공유기의 경우 2.4GHz 대역으로 설정해야 프린터가 인식을 잘합니다. 공유기 비밀번호에 특수문자가 너무 많으면 연결 오류가 날 수 있어 점검이 필요합니다. 프린터와 공유기 간의 거리가 너무 멀다면 연결이 자주 끊길 수 있습니다.

## WPS 버튼을 이용한 간편 연결

공유기와 프린터에 있는 WPS 버튼을 차례대로 누르면 별도의 비밀번호 입력 없이 쉽게 연결됩니다. 프린터 조작부에서 무선 설정 메뉴로 진입해 WPS 푸시 버튼 방식을 선택합니다. 2분 이내에 공유기의 WPS 버튼을 길게 누르면 두 기기 간 통신이 자동으로 이루어집니다. 연결이 완료되면 무선 램프가 깜빡임에서 초록색 점등 상태로 바뀝니다. 이 방법은 화면이 작은 소형 프린터에서 매우 유용하게 쓰입니다.

## 프린터 조작부에서 비밀번호 직접 입력

액정 화면이 있는 캐논 프린터는 설정 메뉴에서 무선 LAN 세팅으로 들어갑니다. 사용 가능한 네트워크 검색을 실행하여 본인의 공유기 SSID를 선택합니다. 리모컨이나 방향키를 이용해 와이파이 암호를 정확하게 입력하고 확인을 누릅니다. 연결 중 메시지가 뜨면 잠시 기다렸다가 설정 완료 화면을 확인합니다. 수동 입력 시 대소문자를 틀리면 연결에 실패하므로 천천히 입력합니다.

## PC 소프트웨어를 통한 설정 방법

캐논 공식 홈페이지에서 프린터 모델명을 검색해 최신 드라이버 및 소프트웨어를 다운로드합니다. 설치 프로그램을 실행하고 연결 유형 선택 단계에서 무선 랜 연결을 체크합니다. 프로그램이 자동으로 네트워크 상의 프린터를 검색하도록 둡니다. 검색된 프린터를 선택하고 화면 안내에 따라 네트워크 설정을 완료합니다. 설치가 끝나면 테스트 페이지 인쇄를 통해 정상 작동을 점검합니다.

## 모바일 앱을 활용한 무선 출력 세팅

스마트폰 앱스토어에서 캐논 전용 프린트 앱을 다운로드하여 실행합니다. 앱 내에서 새 프린터 등록 메뉴를 누르고 무선 네트워크 설정을 진행합니다. 스마트폰의 블루투스 권한이나 위치 권한을 허용해야 주변 기기를 잘 찾습니다. 안내에 따라 프린터와 스마트폰을 임시로 연결한 뒤 와이파이 정보를 전달합니다. 설정이 끝나면 갤러리의 사진이나 문서를 무선으로 곧바로 출력할 수 있습니다.

## 연결 실패 시 네트워크 설정 초기화

와이파이가 자꾸 끊기거나 연결이 안 될 때는 프린터의 네트워크 설정을 초기화해야 합니다. 설정 메뉴에서 네트워크 설정 초기화 항목을 찾아 실행합니다. 초기화가 완료되면 프린터가 공장 출고 상태의 무선 대기 상태로 돌아갑니다. 공유기를 재부팅한 뒤 처음부터 다시 무선 연결 과정을 진행합니다. 문제가 지속되면 캐논 고객센터를 통해 펌웨어 업데이트를 문의합니다.

캐논 프린터 와이파이 연결은 동일 주파수 대역 확인과 올바른 암호 입력이 핵심입니다. 원활한 무선 출력을 누려보세요.
