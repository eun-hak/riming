## 앱스 화면에서 길게 눌러 홈에 추가하기

화면을 아래에서 위로 쓸어올려 모든 어플이 모여 있는 앱스 화면으로 진입합니다. 홈 화면에 꺼내놓고 싶은 앱 아이콘을 손가락으로 2초 이상 지긋이 누르고 있습니다. 손가락을 떼지 않은 상태에서 살짝 움직이면 자동으로 홈 화면으로 화면이 전환됩니다. 원하는 위치에 아이콘을 가져다 놓고 손가락을 떼면 바탕화면에 앱이 곧바로 생성됩니다.

## 팝업 메뉴를 활용한 간편 추가 방법

앱스 화면이나 기존 홈 화면에 있는 앱 아이콘을 길게 누르면 짧은 팝업 메뉴 창이 뜹니다. 메뉴 항목 중에서 홈 화면에 추가라는 문구를 터치하면 가장 첫 번째 빈 공간에 아이콘이 들어갑니다. 이 방식을 사용하면 화면을 직접 끌고 이동하는 번거로움 없이 빠르게 배치할 수 있습니다. 이미 홈 화면에 있는 앱이라면 이 메뉴가 다르게 나타날 수 있으니 참고합니다.

홈 화면에 앱 아이콘이 너무 많아지면 정신없으므로 성격이 비슷한 앱끼리 폴더로 묶어줍니다. 하나의 앱 아이콘을 다른 앱 아이콘 위로 겹쳐서 올려놓으면 자동으로 폴더 생성 화면이 뜹니다. 폴더 이름을 사용자가 직접 지정할 수 있어 나중에 원하는 어플을 찾기가 훨씬 수월해집니다. 폴더 안에서도 아이콘의 순서를 자유롭게 바꾸거나 추가로 앱을 넣을 수 있습니다.
