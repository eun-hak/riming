## 화면 분할을 실행하는 기본 방법

최근 실행한 앱 버튼을 누르거나 제스처를 사용하여 화면 분할을 시작할 수 있습니다. 앱 아이콘을 길게 누르거나 상단바를 끌어내려 화면 분할 아이콘을 선택하십시오. 화면의 절반씩 두 앱을 띄우거나 3분할까지 설정하여 효율적인 배치가 가능합니다. 앱 사이의 경계선을 드래그하면 화면 비율을 자유롭게 조절할 수 있습니다. 처음 사용하는 경우 엣지 패널의 앱 페어를 이용하면 빠르게 분할 모드로 진입합니다.

팝업 화면 기능은 전체 화면 위에 작은 창을 띄워 다른 앱과 함께 사용하는 방식입니다. 앱 실행 후 화면 모서리를 대각선으로 밀거나 최근 앱 목록에서 팝업으로 열기를 선택합니다. 창의 크기와 투명도를 조절할 수 있어 자료를 참고하며 메모할 때 매우 유용합니다. 여러 개의 팝업 창을 동시에 띄워 PC와 유사한 환경을 조성할 수도 있습니다. 창을 최소화하면 아이콘 형태로 유지되어 필요할 때 바로 불러옵니다.

자주 사용하는 두 개의 앱 조합이 있다면 앱 페어 기능을 활용하는 것이 편리합니다. 자주 쓰는 앱 두 개를 분할 화면으로 설정한 뒤 엣지 패널에 즐겨찾기로 등록합니다. 이후 엣지 패널만 누르면 설정해둔 두 앱이 즉시 분할된 상태로 실행됩니다. 이는 학습이나 업무 시 매번 앱을 다시 실행하는 번거로움을 줄여줍니다. 여러 개의 앱 페어를 만들어 상황별로 빠르게 전환하며 사용하십시오.
