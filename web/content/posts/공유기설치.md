공유기설치를 직접 하려는 분들을 위해 모던 인터넷 회선과 공유기를 올바르게 연결하는 순서를 안내합니다. 랜선의 위치를 헷갈리거나 와이파이 비밀번호 설정을 놓치면 속도가 저하되거나 보안에 취약해집니다. 기기를 처음 개봉했을 때부터 스마트폰으로 와이파이를 잡기까지의 모든 과정을 쉽게 풀어냅니다.

## 랜선 포트 올바르게 연결하는 순서

벽면의 모뎀이나 인터넷 단자함에서 나오는 랜선을 공유기의 인터넷 전용 포트에 꽂아야 합니다. 일반적으로 WAN 포트라고 표시되어 있으며 색상이 다른 경우가 많습니다. 컴퓨터나 노트북을 유선으로 연결할 때는 남은 번호가 매겨진 랜 포트에 꽂습니다. 선을 잘못 꽂으면 인터넷이 연결되지 않거나 아이피 충돌이 발생하므로 포트 명칭을 확인해야 합니다.

## 공유기 전원 공급과 작동 상태등 확인

모든 랜선 연결이 끝난 뒤 전원 어댑터를 콘센트에 꽂고 공유기 본체에 연결합니다. 부팅이 완료될 때까지 약 1분에서 2분 정도 소요되며 전원과 와이파이 불빛이 정상 점멸하는지 봅니다. 인터넷 아이콘이나 회선 연결등이 깜빡이지 않고 꺼져 있다면 랜선 접촉 불량을 의심해야 합니다. 기기 재부팅 버튼을 눌러 초기화를 시도하는 것도 문제 해결 방법 중 하나입니다.

## 와이파이 이름과 비밀번호 설정 방법

공유기 바닥면에 적힌 관리자 페이지 주소나 와이파이 기본 이름을 스마트폰 브라우저에 입력합니다. 초기 관리자 계정으로 로그인한 뒤 무선 네트워크 설정 메뉴로 이동합니다. 사용자가 쉽게 알아볼 수 있는 와이파이 이름을 지정하고 타인이 접속하지 못하도록 비밀번호를 설정합니다. 보안 설정을 하지 않으면 주변에서 무단으로 사용하여 인터넷 속도가 급격히 느려집니다.

## 관리자 페이지 접속 불가 시 대처법

주소를 입력해도 관리자 페이지가 열리지 않는다면 와이파이 연결 상태나 공유기 기종을 점검해야 합니다. 스마트폰의 모바일 데이터를 잠시 끄고 해당 공유기의 와이파이에만 연결된 상태에서 접속을 시도합니다. 주소가 기억나지 않는다면 제품 뒷면에 적힌 기본 IP 주소를 정확히 입력했는지 확인합니다. 그래도 안 될 때는 바늘로 리셋 구멍을 5초 이상 눌러 공장 초기화 상태로 되돌립니다.

## 음영 지역 없애는 공유기 설치 위치

공유기는 집안의 중앙에 장애물이 적은 높은 곳에 설치해야 전파가 집 전체로 골고루 퍼집니다. 두꺼운 콘크리트 벽 뒤나 싱크대 하단, 신발장 안에 넣으면 와이파이 수신율이 크게 떨어집니다. 집이 넓거나 복층 구조라면 메인 공유기 외에 무선 확장기를 추가로 설치해야 합니다. 랜선 배치가 어렵다면 메시 와이파이 기능을 지원하는 제품을 선택하는 것이 유리합니다.

## 인터넷 속도가 느려질 때 체크할 점

와이파이 연결은 되는데 웹서핑 속도가 비정상적으로 느리다면 공유기의 2.4기가헤르츠와 5기가헤르츠 대역을 구분해야 합니다. 속도가 빠른 5기가헤르츠 대역은 장애물에 약하므로 공유기와 가까운 곳에서 접속합니다. 동시 접속 기기가 너무 많거나 구형 공유기 칩셋인 경우 기기 성능의 한계일 수 있습니다. 통신사 모뎀과 공유기의 전원을 동시에 껐다가 30초 뒤에 켜는 방식으로 속도를 회복시킵니다.

공유기 설치는 WAN 포트 연결과 관리자 페이지를 통한 비밀번호 설정이 핵심입니다. 올바른 위치 선정을 통해 끊김 없는 와이파이 환경을 구축하시기 바랍니다.
