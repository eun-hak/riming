IPTIME 공유기 설치는 기기 연결 후 설정 페이지에 접속하여 인터넷 환경을 구성하는 과정으로 이루어집니다. 모바일 앱이나 PC 브라우저를 통해 누구나 쉽게 단계별 설정을 진행할 수 있습니다. 올바른 포트 연결과 무선 네트워크 암호 설정이 설치의 핵심입니다.

## 공유기 하드웨어 연결 방법

공유기 본체에 전원 어댑터를 연결하고 WAN 포트에 메인 인터넷 선을 꽂습니다. WAN 포트는 보통 다른 포트와 색상이 구분되어 있어 쉽게 찾을 수 있습니다. 나머지 포트에는 PC나 게임기 등을 연결할 수 있는 LAN 케이블을 꽂습니다. 전원을 켜면 공유기 전면의 LED가 깜빡이며 부팅을 시작합니다. 모든 케이블이 헐겁지 않게 단단히 고정되었는지 확인하는 것이 중요합니다.

## 설정 페이지 접속하기

공유기와 연결된 PC나 스마트폰에서 웹 브라우저를 열고 주소창에 192.168.0.1을 입력합니다. IPTIME 설정 페이지가 나타나면 초기 아이디와 비밀번호를 입력합니다. 초기값은 보통 admin으로 설정되어 있습니다. 로그인이 성공하면 관리 도구 메뉴를 통해 본격적인 설정을 시작할 수 있습니다. 비밀번호를 잊어버린 경우 공유기 뒷면의 초기화 버튼을 길게 눌러 초기화할 수 있습니다.

## 인터넷 연결 자동 설정

관리 도구 내 인터넷 설정 정보 메뉴에서 자동으로 인터넷 연결을 검색합니다. 대부분의 가정용 인터넷은 별도의 입력 없이 자동으로 IP를 할당받습니다. 연결 상태가 정상으로 표시되면 인터넷 사용이 가능해집니다. 만약 연결이 되지 않는다면 통신사 모뎀과의 호환성 문제일 수 있으므로 모뎀을 재부팅한 뒤 다시 시도합니다. 설정이 완료되면 적용 버튼을 눌러 변경 사항을 저장합니다.

## 무선 네트워크 이름 및 암호 설정

무선 설정 보안 메뉴에서 와이파이 이름을 변경하고 비밀번호를 설정합니다. 암호는 타인의 무단 접속을 방지하기 위해 반드시 설정해야 합니다. 암호화 방식은 WPA2PSK와 AES 조합을 권장하며 보안성이 높습니다. 설정 후 적용하면 기존 와이파이 연결이 끊어지며 변경된 이름으로 다시 접속해야 합니다. 새로운 비밀번호를 입력하여 정상적으로 연결되는지 확인합니다.

## 관리자 페이지 비밀번호 보안

공유기 설정 페이지에 타인이 접속하지 못하도록 관리자 계정 비밀번호를 변경해야 합니다. 시스템 관리 메뉴 내 관리자 설정에서 비밀번호를 새로 지정합니다. 초기 비밀번호를 그대로 두면 보안에 취약하여 해킹의 표적이 될 수 있습니다. 변경된 비밀번호는 분실하지 않도록 기록해 두는 것이 좋습니다. 관리자 계정 비밀번호를 설정하면 공유기 보안이 한층 강화됩니다.

## 펌웨어 업데이트 및 유지보수

공유기의 안정적인 성능을 위해 최신 펌웨어로 업데이트하는 것이 좋습니다. 시스템 관리 메뉴 내 펌웨어 업그레이드 항목을 확인하여 자동 업데이트를 수행합니다. 업데이트 중에는 전원을 절대 끄지 않아야 합니다. 주기적으로 펌웨어를 관리하면 공유기의 보안 취약점이 개선되고 속도가 향상될 수 있습니다. 설치 후 일 년에 한두 번 정도 업데이트 상태를 확인하십시오.

IPTIME 공유기 설치는 기기 연결 후 웹 관리 페이지에서 간단히 수행할 수 있습니다. 보안을 위해 와이파이 암호와 관리자 비밀번호를 반드시 설정하시기 바랍니다.
