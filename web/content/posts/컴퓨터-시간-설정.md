컴퓨터 시간이 맞지 않으면 웹사이트 접속 오류나 보안 인증 실패가 발생할 수 있습니다. 윈도우 설정에서 자동으로 시간을 동기화하거나 수동으로 조정하여 문제를 해결할 수 있습니다. 메인보드 배터리 방전이 원인이라면 시간 설정만으로는 근본적인 해결이 어렵습니다. 상황별 시간 설정 방법과 점검 항목을 상세히 알아봅니다.

## 윈도우 설정 메뉴를 통한 자동 시간 동기화

윈도우 하단 작업표시줄의 날짜와 시간 영역을 우클릭하여 날짜 및 시간 조정 메뉴로 진입합니다. 시간 자동 설정 옵션을 켬 상태로 변경하면 인터넷 표준 시간과 동기화됩니다. 만약 시간이 여전히 맞지 않는다면 하단의 지금 동기화 버튼을 누릅니다. 동기화가 성공하면 현재 시간으로 즉시 변경됩니다. 네트워크 연결 상태가 양호해야 동기화가 원활합니다.

## 수동으로 날짜 및 시간 설정 변경하기

자동 설정이 불가능한 환경이라면 수동으로 직접 입력해야 합니다. 시간 자동 설정 스위치를 끔으로 변경한 뒤 날짜 및 시간 변경 버튼을 클릭합니다. 나타나는 창에서 연도, 월, 일, 시간을 직접 입력하고 변경 버튼을 누릅니다. 지역 설정이 한국 표준시로 되어 있는지 반드시 확인하십시오. 잘못된 지역 설정은 자동 동기화 오류의 주요 원인입니다.

## 메인보드 수은 배터리 방전 여부 확인

컴퓨터를 켤 때마다 시간이 초기화된다면 메인보드의 수은 배터리 방전을 의심해야 합니다. 전원이 차단된 상태에서도 메인보드 내부의 시계는 배터리를 통해 작동합니다. 배터리 전압이 낮아지면 시스템은 시간을 기억하지 못하고 초기값으로 돌아갑니다. CR2032 규격의 배터리를 구매하여 교체하면 반영구적으로 문제를 해결할 수 있습니다.

## 인터넷 시간 서버 설정 변경을 통한 오류 해결

동기화 버튼을 눌러도 오류가 발생한다면 시간 서버를 변경해 봅니다. 제어판의 날짜 및 시간 설정에서 인터넷 시간 탭으로 이동합니다. 설정 변경을 클릭한 뒤 서버 주소를 time.windows.com에서 time.google.com 등으로 바꿉니다. 서버 주소를 변경한 후 다시 지금 업데이트를 시도합니다. 특정 서버의 일시적 장애일 경우 해결 가능합니다.

## 시스템 파일 손상 및 서비스 상태 점검

시간 관련 서비스인 Windows Time이 실행 중인지 확인해야 합니다. 윈도우 키와 R을 눌러 실행 창에 services.msc를 입력합니다. 목록에서 Windows Time 서비스를 찾아 마우스 우클릭 후 시작을 누릅니다. 시작 유형을 자동으로 설정하면 부팅 시마다 자동으로 시간이 동기화됩니다. 서비스가 이미 실행 중이라면 재시작을 시도하십시오.

## 바이오스 진입을 통한 하드웨어 시간 확인

윈도우 진입 전 메인보드 바이오스 화면에서도 시간을 확인할 수 있습니다. 컴퓨터를 켤 때 Del 또는 F2 키를 눌러 바이오스 설정창으로 진입합니다. 메인 화면에 표시되는 System Time이 현재와 다르다면 여기서 수정합니다. 여기서 변경한 시간은 윈도우에도 영향을 미칩니다. 바이오스에서 시간이 틀리다면 배터리 교체가 시급합니다.

컴퓨터 시간 오류는 대부분 윈도우 설정에서 자동 동기화로 해결됩니다. 반복적으로 시간이 틀어진다면 메인보드 배터리 교체를 고려하십시오.
