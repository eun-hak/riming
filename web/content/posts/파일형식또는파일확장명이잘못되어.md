파일형식또는파일확장명이잘못되어 문서를 열 수 없다는 오류는 엑셀이나 워드 파일을 실행할 때 주로 발생합니다. 확장자가 실제 파일 포맷과 일치하지 않거나 비정상적인 종료로 인해 손상되었을 때 나타납니다. 업무 문서나 중요한 데이터를 복구하고 정상적으로 실행하는 대처법을 알아봅니다.

## 파일 확장자 수동 변경 및 확인

윈도우 탐색기 설정에서 파일 확장명 숨기기 체크를 해제하여 실제 확장자가 무엇인지 확인해야 합니다. 엑셀 파일이라면 뒤에 붙은 확장자가 .xlsx 혹은 .xls로 올바르게 지정되어 있는지 점검합니다. 다운로드 과정에서 이름이 임의로 바뀌었거나 다른 형식으로 저장된 경우 올바른 확장자로 수정하면 해결되기도 합니다. 단, 단순히 확장자만 바꾸는 것은 실제 데이터 구조가 다를 경우 오류를 유발할 수 있습니다.

## 오피스 프로그램의 열기 및 복구 기능

엑셀이나 워드를 먼저 실행한 뒤 파일 메뉴에서 열기를 선택하고 문제가 되는 문서를 찾습니다. 열기 버튼 우측의 화살표를 눌러 열기 및 복구 항목을 클릭하면 손상된 데이터를 자동으로 복원 시도합니다. 프로그램이 자체적으로 손상된 텍스트나 수식을 수리하여 읽을 수 있는 상태로 변환해 줍니다. 완벽한 복구가 되지 않더라도 일부 데이터는 건질 수 있어 유용한 방법입니다.

## 임시 파일 및 백업 파일 활용하기

오피스 프로그램은 작업 중 자동으로 임시 파일을 생성하므로 이를 찾아 확장자를 변경해 복구할 수 있습니다. 윈도우 앱데이터 폴더 내의 임시 저장 경로에서 유사한 이름의 파일을 찾아 확장자를 .xlsx로 바꿉니다. 자동 복구 기능이 켜져 있었다면 프로그램 재실행 시 왼쪽에 복구된 문서 목록이 나타납니다. 정기적으로 백업해 둔 파일이 있다면 최신 버전을 활용하는 것이 가장 확실합니다.

## 웹 뷰어 또는 다른 프로그램으로 열기

로컬 PC의 오피스 프로그램 버전 문제로 파일이 열리지 않는다면 구글 드라이브나 네이버 클라우드에 업로드합니다. 웹 브라우저 기반의 오피스 뷰어를 통해 파일을 열면 구버전과 신버전 간의 호환성 문제를 우회할 수 있습니다. 한컴오피스나 전용 문서 뷰어 프로그램을 이용해 다른 형식으로 변환 저장을 시도해 보는 것도 방법입니다. 외부 프로그램으로 열린다면 내용을 복사하여 새 문서에 붙여넣기 할 수 있습니다.

## 파일 압축 해제 프로그램으로 내부 확인

엑셀 .xlsx 파일은 내부적으로 압축된 XML 구조로 이루어져 있어 반디집이나 알집으로 열어볼 수 있습니다. 확장자를 .zip으로 임의 변경한 뒤 압축을 풀면 내부 시트 데이터와 이미지 폴더를 확인할 수 있습니다. 문서 전체가 완전히 깨지지 않았다면 내부의 xl 폴더 안에서 텍스트 데이터를 추출할 수 있습니다. 고급 사용자용 복구 방법으로 손상된 헤더 정보를 우회할 때 활용됩니다.

## 바이러스 검사 및 디스크 오류 확인

파일이 저장된 USB 메모리나 하드디스크의 섹터 불량으로 인해 파일 헤더가 손상되었을 가능성이 있습니다. 윈도우 기본 백신이나 전문 보안 프로그램을 통해 악성코드 감염 여부를 먼저 검사해야 합니다. 외장 저장장치라면 오류 검사 도구를 실행하여 파일 시스템 손상을 복구한 뒤 파일을 다시 열어봅니다. 네트워크 드라이브에 있는 파일이라면 로컬 PC로 복사한 후 실행을 시도합니다.

파일형식또는파일확장명이잘못되어 발생하는 오류는 확장자 수정과 오피스 자체 복구 기능을 통해 상당 부분 해결할 수 있습니다. 정기적인 백업 습관으로 데이터 유실에 대비하시기 바랍니다.
