최근 출시된 스마트 폴더폰을 사용하면서 와이파이 연결 방법을 몰라 데이터를 낭비하는 경우가 많습니다. 폴더폰이라 하더라도 안드로이드 기반의 스마트폰 기능을 갖추고 있다면 와이파이 설정은 일반 스마트폰과 거의 동일합니다. 데이터를 절약하고 빠른 인터넷 환경을 구축하기 위해 폴더폰에서 와이파이를 연결하는 기본적인 절차를 정리했습니다. 기기 설정 메뉴를 차근차근 따라 해 보시기 바랍니다.

## 설정 메뉴에서 와이파이 항목 찾기

폴더폰을 열고 메뉴 버튼을 눌러 설정 애플리케이션으로 진입하세요. 설정 리스트 중에서 '연결' 혹은 '네트워크 및 인터넷' 항목을 선택합니다. 그 안에 있는 'Wi-Fi' 메뉴를 클릭하면 현재 주변에서 잡히는 네트워크 목록이 나타납니다. 만약 와이파이 기능이 꺼져 있다면 스위치를 눌러 '켜짐' 상태로 활성화해야 합니다. 이 단계가 가장 기초이며, 스마트폰과 거의 다르지 않은 인터페이스를 가지고 있습니다.

## 주변 네트워크 선택 및 비밀번호 입력

활성화된 와이파이 목록에서 본인이 사용하는 공유기 이름을 선택하세요. 비밀번호가 설정된 네트워크라면 입력창이 팝업됩니다. 폴더폰의 키패드를 이용해 영문과 숫자를 정확히 입력해야 합니다. 비밀번호를 입력할 때 대소문자를 구분해야 하므로 키패드의 문자 전환 기능을 잘 활용하세요. 입력이 완료되면 연결 버튼을 누르고 잠시 기다리면 됩니다. 연결됨이라는 표시가 나타나면 정상적으로 와이파이를 사용할 수 있습니다.

## 고정 IP 및 상세 설정 확인

만약 와이파이가 연결되지 않는다면 네트워크의 상세 설정을 확인해야 합니다. 특정 공유기는 보안 설정이 까다로워 연결이 안 될 수 있습니다. 네트워크 이름 옆의 톱니바퀴 아이콘을 누르면 상세 설정 메뉴로 들어갈 수 있습니다. 여기서 IP 설정을 DHCP로 되어 있는지 확인하고, 필요하다면 다시 연결을 시도해 보세요. 보안 방식이 WPA3 등 최신 방식일 경우 폴더폰이 지원하지 않을 수도 있으니 참고하시기 바랍니다.

## 상단 상태 표시줄의 연결 아이콘 확인

연결이 성공하면 폴더폰 화면 상단 상태 표시줄에 부채꼴 모양의 와이파이 아이콘이 나타납니다. 이 아이콘이 떠 있다면 데이터 요금 걱정 없이 인터넷을 사용할 수 있다는 뜻입니다. 만약 아이콘이 보이지 않는다면 연결이 끊겼거나 와이파이 신호가 너무 약한 경우입니다. 신호가 약하다면 공유기 근처로 이동하거나 다시 연결을 시도해 보세요. 아이콘 유무를 통해 실시간으로 연결 상태를 확인할 수 있습니다.

## 데이터 자동 전환 방지 설정

와이파이 신호가 불안정하면 기기가 자동으로 모바일 데이터로 전환될 수 있습니다. 이를 방지하려면 설정에서 '모바일 데이터로 자동 전환' 옵션을 꺼두는 것이 좋습니다. 데이터 요금제가 제한적이라면 이 설정이 매우 중요합니다. 설정 메뉴의 Wi-Fi 고급 설정에서 관련 항목을 찾아 비활성화하세요. 이렇게 하면 와이파이가 끊겨도 데이터가 자동으로 소모되지 않아 요금 폭탄을 예방할 수 있습니다.

## 공공 와이파이 사용 시 주의사항

카페나 지하철 같은 공공장소에서 무료 와이파이를 사용할 때는 보안에 유의해야 합니다. 비밀번호가 없는 와이파이는 해킹 위험이 있으므로 중요한 금융 거래는 피하는 것이 좋습니다. 폴더폰이라도 안드로이드 기반이므로 보안 취약점은 일반 스마트폰과 동일합니다. 가능하면 보안이 확인된 가정용 와이파이를 주로 사용하고, 공공 와이파이는 단순 정보 검색용으로만 활용하세요. 연결 후 사용이 끝나면 와이파이를 끄는 습관도 좋습니다.

폴더폰의 와이파이 설정은 메뉴 위치만 익히면 매우 간단합니다. 데이터 절약을 위해 와이파이 활용법을 숙지하시고 안전하게 인터넷을 이용하시기 바랍니다.
