갤럭시 스마트폰의 분할 화면 기능을 사용하면 두 개의 앱을 동시에 띄워 효율적으로 멀티태스킹을 할 수 있습니다. 영상 시청과 메신저 답장을 동시에 하거나 웹 서핑 중 메모를 할 때 매우 유용한 기능입니다. 최신 원 UI 버전에 따라 실행 방법이 조금씩 다르지만, 기본 개념은 동일합니다. 갤럭시에서 분할 화면을 빠르고 정확하게 실행하여 스마트폰 활용도를 높이는 방법을 안내해 드립니다.

## 최근 실행 앱 버튼을 통한 분할 화면 실행

가장 먼저 화면 하단의 내비게이션 바에서 '최근 실행 앱' 버튼(세로선 세 개 아이콘)을 누르십시오. 현재 실행 중인 앱들의 목록이 나타나면 상단의 앱 아이콘을 터치합니다. 메뉴 창이 뜨면 '분할 화면으로 열기'를 선택하십시오. 이후 나머지 화면에 띄울 다른 앱을 선택하면 두 개의 앱이 위아래로 나뉘어 동시에 실행됩니다.

## 앱 엣지 패널을 활용한 빠른 실행

자주 사용하는 앱은 엣지 패널에 등록해 두면 더욱 빠르게 분할 화면을 만들 수 있습니다. 화면 측면의 엣지 핸들을 밀어 패널을 열고 원하는 앱을 길게 눌러 화면으로 드래그하십시오. 화면의 상단이나 하단으로 끌어다 놓으면 해당 영역에 앱이 고정됩니다. 이 방식은 버튼을 여러 번 누를 필요가 없어 멀티태스킹 속도를 획기적으로 높여줍니다.

## 분할 화면 크기 조절 및 위치 변경

두 앱 사이의 경계선에 있는 점 세 개 아이콘을 누르면 크기를 조절하거나 위치를 바꿀 수 있습니다. 아이콘을 위아래로 드래그하여 원하는 비율로 화면을 나누십시오. 화살표 모양의 아이콘을 누르면 위아래 앱의 위치가 즉시 바뀝니다. 작업 중인 앱의 중요도에 따라 화면 크기를 실시간으로 변경하며 사용할 수 있어 매우 편리합니다.

## 분할 화면 앱 페어 저장하기

자주 같이 사용하는 앱 조합이 있다면 '앱 페어'로 저장하십시오. 분할 화면 상태에서 경계선의 점 세 개 아이콘을 누르고 별 모양 아이콘을 선택하면 엣지 패널에 해당 조합이 저장됩니다. 다음부터는 엣지 패널에서 그 아이콘만 누르면 두 앱이 동시에 분할 화면으로 즉시 실행됩니다. 업무용이나 학습용으로 자주 쓰는 조합을 저장해두면 시간을 크게 절약합니다.

## 분할 화면 지원 여부 확인하기

모든 앱이 분할 화면을 지원하는 것은 아닙니다. 일부 앱은 개발사 정책에 따라 분할 화면 기능을 막아두었을 수 있습니다. 설정의 '실험실' 메뉴에서 '모든 앱에서 멀티 윈도우 지원' 옵션을 켜면 강제로 분할 화면을 사용할 수 있게 됩니다. 다만 이 경우 앱의 레이아웃이 깨질 수 있으니 꼭 필요한 경우에만 설정하여 사용하시기 바랍니다.

## 분할 화면 종료하는 방법

분할 화면을 종료하려면 경계선 아이콘을 화면 끝까지 드래그하면 됩니다. 한쪽 앱을 위나 아래로 완전히 밀어버리면 나머지 앱이 전체 화면으로 전환됩니다. 또한 내비게이션 바의 뒤로 가기 버튼을 누르거나 홈 버튼을 눌러 멀티태스킹 창을 닫을 수도 있습니다. 상황에 맞는 종료 방식을 선택하여 간편하게 원래 상태로 돌아오십시오.

갤럭시 분할 화면은 최근 앱 버튼이나 엣지 패널을 통해 쉽게 실행됩니다. 앱 페어 기능을 활용하여 본인만의 멀티태스킹 환경을 구축해 보시기 바랍니다.
