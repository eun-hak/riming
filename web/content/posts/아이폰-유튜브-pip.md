아이폰에서 유튜브 PIP(Picture-in-Picture) 기능을 사용하면 영상을 작은 창으로 띄워 다른 앱을 동시에 사용할 수 있습니다. 이 기능은 유튜브 프리미엄 구독자라면 별도의 설정 없이 바로 사용 가능하며, 무료 이용자는 제약이 있을 수 있습니다. 아이폰 설정법과 PIP가 작동하지 않을 때 확인해야 할 체크리스트를 정리합니다. 화면 속 화면 기능을 통해 스마트폰 활용도를 높여 보십시오.

## 유튜브 프리미엄과 PIP 기능

유튜브 프리미엄 구독자는 공식 앱의 설정 메뉴에서 PIP 기능을 활성화할 수 있습니다. 앱 내 설정에서 '일반' 탭으로 들어가 '화면 속 화면' 항목을 켜면 준비가 완료됩니다. 이후 영상을 시청하다가 홈 화면으로 나가면 자동으로 영상이 작은 창으로 변환됩니다. 이는 아이폰의 시스템 설정보다 앱 내 설정이 우선하므로 반드시 앱 설정을 먼저 확인해야 합니다.

## 아이폰 iOS 시스템 설정 확인

유튜브 앱 설정 외에도 아이폰 자체 설정에서 PIP가 허용되어 있는지 확인해야 합니다. '설정' 앱에서 '일반'을 선택하고 '화면 속 화면' 메뉴로 들어갑니다. '화면 속 화면 시작' 옵션이 켜져 있어야 합니다. 이 옵션이 꺼져 있으면 유튜브뿐만 아니라 다른 영상 앱에서도 PIP가 작동하지 않습니다. 시스템 설정은 모든 영상 앱에 적용되는 공통 사항입니다.

## 무료 이용자의 PIP 사용 제한

한국을 포함한 일부 국가에서는 무료 이용자의 경우 유튜브 앱에서 PIP 기능을 사용하는 데 제약이 있습니다. 음악이나 특정 카테고리 영상은 PIP가 차단되는 경우가 많습니다. 웹 브라우저를 통해 유튜브에 접속하여 영상 전체 화면 모드에서 홈 화면으로 나가는 우회 방법을 사용하기도 하지만, 이는 공식적인 기능이 아니며 정책 변경에 따라 막힐 수 있습니다.

## PIP가 작동하지 않을 때 해결법

PIP 기능이 갑자기 작동하지 않는다면 앱을 완전히 종료했다가 다시 실행해 보십시오. 앱 업데이트가 되지 않았을 때도 기능 오류가 발생할 수 있으니 앱스토어에서 유튜브 앱이 최신 버전인지 체크합니다. 만약 특정 영상에서만 안 된다면 해당 영상 제작자가 PIP 기능을 제한한 경우일 수 있습니다. 아이폰을 재부팅하면 일시적인 시스템 꼬임 현상이 해결되기도 합니다.

## 멀티태스킹 시 화면 조절 방법

PIP 창은 두 손가락으로 확대하거나 축소하여 크기를 조절할 수 있습니다. 화면 귀퉁이로 밀어 넣으면 영상 소리만 재생되도록 숨길 수도 있습니다. 다시 보고 싶을 때는 화면 가장자리에 생긴 화살표 아이콘을 누르면 됩니다. PIP 창의 위치는 화면 어디로든 자유롭게 이동이 가능하여 다른 앱 사용 시 방해가 되지 않게 배치할 수 있습니다.

## PIP 모드 종료 및 복구

영상 창을 닫으려면 창 내부에 있는 'X' 버튼을 누르거나, 창을 화면 밖으로 밀어내어 종료할 수 있습니다. 다시 전체 화면으로 돌아가려면 창 중앙의 아이콘을 누르면 됩니다. PIP 모드는 아이폰의 멀티태스킹을 극대화하는 기능이므로, 웹 서핑이나 메신저를 사용하면서 영상을 시청해야 할 때 매우 유용합니다. 설정을 완료하여 편리하게 이용하십시오.

아이폰 유튜브 PIP는 프리미엄 구독 시 가장 원활하게 사용할 수 있습니다. 설정 내 화면 속 화면 옵션을 활성화하고 앱 버전을 최신으로 유지하십시오. 멀티태스킹 기능을 통해 영상 시청과 작업의 효율을 높일 수 있습니다.
