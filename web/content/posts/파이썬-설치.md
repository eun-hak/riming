파이썬은 데이터 분석, 웹 개발, 자동화 등 다양한 분야에서 사용되는 필수 프로그래밍 언어입니다. 공식 홈페이지를 통해 설치 파일을 내려받고 환경 변수를 제대로 설정해야 터미널에서 파이썬 명령어를 자유롭게 사용할 수 있습니다. 운영체제별 설치 과정과 초기 설정 방법을 단계별로 안내해 드립니다.

## 공식 홈페이지에서 설치 파일 다운로드

파이썬 공식 웹사이트인 python.org에 접속하여 Downloads 메뉴를 클릭합니다. 자신의 운영체제에 맞는 최신 버전의 설치 파일을 내려받으십시오. 윈도우 사용자는 64비트 설치 파일을 선택하는 것이 권장됩니다. 설치 시 주의할 점은 반드시 하단에 있는 'Add Python to PATH' 항목을 체크해야 합니다. 이 옵션을 체크해야 터미널에서 파이썬을 즉시 호출할 수 있습니다.

## 윈도우 환경 변수 설정 확인

설치 과정에서 PATH 추가를 놓쳤다면 수동으로 설정해야 합니다. 윈도우 검색창에 '시스템 환경 변수 편집'을 입력하고 창을 엽니다. 환경 변수 버튼을 누른 뒤 사용자 변수에서 Path를 찾아 편집을 누릅니다. 새로 만들기를 클릭하고 파이썬이 설치된 경로와 Scripts 폴더 경로를 추가합니다. 명령 프롬프트를 다시 실행하고 python --version을 입력해 정상 설치 여부를 확인하십시오.

## 맥(macOS) 환경에서의 파이썬 설치

맥은 기본적으로 파이썬이 설치되어 있는 경우가 많지만 버전이 낮을 수 있습니다. 터미널에서 brew install python 명령어를 입력하여 홈브루를 통해 최신 버전을 설치하는 것이 관리하기 좋습니다. 설치 완료 후 파이썬 경로를 확인하려면 which python3 명령어를 사용하십시오. 쉘 설정 파일에 별칭을 추가하면 python 명령어로도 최신 버전을 호출할 수 있습니다.

## 패키지 관리자 pip의 역할

파이썬 설치와 함께 자동으로 설치되는 pip는 외부 라이브러리를 관리하는 도구입니다. 터미널에서 pip install 패키지명 명령어를 통해 필요한 기능을 손쉽게 추가할 수 있습니다. 예를 들어 데이터 분석을 위해 pandas 라이브러리를 설치할 때 pip를 사용합니다. 파이썬 버전을 업데이트할 때는 pip 자체도 최신 버전으로 업그레이드하는 것이 좋습니다. pip --version으로 설치 상태를 먼저 확인하십시오.

## 가상 환경 구성의 필요성

프로젝트마다 필요한 라이브러리 버전이 다를 수 있으므로 가상 환경을 사용하는 것이 좋습니다. 파이썬 내장 모듈인 venv를 활용해 프로젝트 폴더별로 독립적인 환경을 만드십시오. python -m venv venv 명령어를 입력하면 해당 폴더에 가상 환경이 생성됩니다. 가상 환경을 활성화하면 설치된 라이브러리가 다른 프로젝트에 영향을 주지 않습니다. 이는 개발 환경을 깨끗하게 유지하는 가장 좋은 방법입니다.

## 통합 개발 환경 IDE 선택

파이썬 코드를 작성하기 위해 VS Code나 PyCharm 같은 IDE를 설치하십시오. 이러한 툴은 코드 자동 완성, 디버깅, 가상 환경 연동 기능을 제공하여 개발 생산성을 크게 높여줍니다. 설치 후 파이썬 인터프리터를 올바르게 선택해야 코드가 정상적으로 실행됩니다. 코드 편집기 설정에서 파이썬 확장 프로그램을 설치하면 문법 강조와 오류 검사도 실시간으로 가능합니다.

파이썬 설치는 환경 변수와 가상 환경 설정만 주의하면 누구나 쉽게 시작할 수 있습니다. 이제 자신만의 코드를 작성하며 프로그래밍의 세계를 경험해 보시기 바랍니다.
