엑셀 작업을 하다가 갑작스러운 오류로 파일이 닫히거나 저장하지 못하는 상황이 발생할 수 있습니다. 엑셀에는 자체적인 자동 복구 기능이 있어 이를 통해 파일을 되살릴 수 있는 가능성이 큽니다. 또한 손상된 파일도 내장 도구를 통해 복구 시도가 가능합니다. 당황하지 말고 아래 단계별 방법을 시도해 보시기 바랍니다.

## 자동 복구 기능 활용

엑셀을 다시 실행하면 '문서 복구' 창이 자동으로 뜨는 경우가 있습니다. 여기서 임시 저장된 파일 목록을 확인하고 원하는 파일을 선택해 저장하십시오. 만약 창이 뜨지 않는다면 '파일' 탭의 '정보' 메뉴로 들어갑니다. '통합 문서 관리' 항목에서 '저장되지 않은 통합 문서 복구'를 클릭하면 임시 폴더가 열립니다. 여기서 최근 작업한 파일을 찾을 수 있습니다.

## 임시 파일 수동 검색

자동 복구 목록에도 없다면 윈도우 임시 폴더를 직접 확인해야 합니다. 파일 탐색기에서 'AppData' 경로를 찾아 'Microsoft\Excel' 폴더로 이동하십시오. 이곳에 확장자가 .tmp나 .asd인 파일이 있다면 엑셀로 열어 내용을 확인합니다. 파일 이름이 암호화되어 있을 수 있으니 날짜를 기준으로 정렬하여 찾으십시오. 중요한 작업이라면 이 폴더를 수시로 확인하는 습관이 도움이 됩니다.

## 손상된 파일 열기 및 복구

파일이 열리지 않거나 오류 메시지가 뜬다면 '열기' 기능을 활용하십시오. 파일 선택 창에서 파일을 클릭한 뒤 '열기' 버튼 옆의 화살표를 누릅니다. '열기 및 복구' 항목을 선택하면 엑셀이 자체적으로 오류를 진단하고 수정을 시도합니다. '데이터 추출'을 선택하여 수식 대신 값만이라도 살려낼 수 있습니다. 이 과정에서 일부 서식이 깨질 수 있음을 인지하십시오.

## 이전 버전 복원 방법

파일을 수정하다가 잘못된 경우 윈도우의 '이전 버전' 기능을 사용할 수 있습니다. 파일 우클릭 후 '속성'에서 '이전 버전' 탭을 확인하십시오. 윈도우 백업 기능이 켜져 있다면 이전 날짜의 파일을 복원할 수 있습니다. 클라우드 서비스인 원드라이브를 사용 중이라면 '버전 기록'을 통해 과거 상태로 되돌립니다. 클라우드 자동 저장은 데이터 유실 방지에 매우 효과적입니다.

## 파일 형식 변환 시도

파일 자체의 구조적 문제라면 다른 형식으로 저장을 시도해 보십시오. .xlsx 파일을 .xls나 .html로 변환하여 열면 데이터가 읽히는 경우가 있습니다. 파일을 열 수만 있다면 다른 이름으로 저장하여 복구된 파일을 새로 만듭니다. 구조적 오류를 해결하는 과정에서 일부 데이터 소실은 감수해야 할 수 있습니다. 다양한 형식으로 변환하며 최선의 결과물을 찾으십시오.

## 데이터 복구 전문 소프트웨어

위의 방법들로 해결되지 않는다면 전문 복구 소프트웨어를 고려하십시오. 하드디스크 자체의 삭제된 파일을 스캔하여 엑셀 파일을 되살리는 도구들이 있습니다. 다만 비용이 발생하며 100% 복구를 보장하지는 않습니다. 무료 체험판으로 파일이 인식되는지 먼저 확인한 뒤 결제하십시오. 가장 중요한 것은 작업 중 수시로 저장하는 습관입니다.

엑셀 복구는 자동 저장 기능과 이전 버전 확인을 통해 가능합니다. 중요한 데이터는 항상 이중으로 백업하고 수시로 저장하는 습관이 가장 확실한 예방법입니다. 기술적인 해결이 어렵다면 전문가의 도움을 고려하십시오.
