유선 랜선을 컴퓨터에 꽂았는데 인터넷 연결이 안 되고 동시에 무선 와이파이마저 잡히지 않는 상황은 매우 당혹스럽습니다. 네트워크 하드웨어 장치에 오류가 생겼거나 랜카드 드라이버가 손상되었을 가능성이 높습니다. 이럴 때 순차적으로 시도해 볼 수 있는 자가 진단 및 복구 방법을 짚어보겠습니다.

## 유무선 공유기와 모뎀 전원 재부팅하기

컴퓨터 자체의 문제보다 가정에 설치된 인터넷 공유기나 모뎀의 일시적 오류일 확률이 큽니다. 랜선과 전원 케이블을 모뎀과 공유기에서 모두 뽑은 뒤 1분 정도 기다립니다. 전원선을 다시 꽂고 공유기 불빛이 정상적으로 깜빡이며 부팅될 때까지 기다립니다. 장비가 완전히 켜진 후 컴퓨터를 재부팅하여 인터넷 신호가 들어오는지 확인합니다.

## 랜선 케이블 물리적 연결 상태 및 포트 점검

컴퓨터 본체 뒤쪽 랜 포트와 공유기 단자에 랜선이 딸깍 소리가 나도록 제대로 꽂혀 있는지 확인합니다. 케이블 피복이 벗겨졌거나 단선된 흔적이 있다면 다른 정상 랜선으로 교체해서 테스트합니다. 벽면 랜 단자를 사용하는 경우 단자함 내부 스위칭 허브나 포트 불량일 수도 있습니다. 다른 포트에 꽂아보며 물리적인 하드웨어 이상 여부를 꼼꼼히 체크합니다.

## 장치 관리자에서 네트워크 어댑터 드라이버 확인

윈도우 시작 버튼을 마우스 우클릭하여 장치 관리자 메뉴로 진입합니다. 네트워크 어댑터 목록을 펼쳐서 랜카드나 무선 와이파이 장치에 노란색 느낌표가 떠 있는지 봅니다. 드라이버 충돌이나 오류로 인해 장치가 비활성화되어 있을 수 있습니다. 장치를 마우스 우클릭하여 디바이스 사용 또는 드라이버 업데이트를 실행합니다.

## 명령 프롬프트에서 네트워크 IP 및 DNS 초기화

윈도우 검색창에 cmd를 입력하여 명령 프롬프트를 관리자 권한으로 실행합니다. 검은색 창이 뜨면 ipconfig /release를 입력해 기존 IP 주소를 해제합니다. 이어서 ipconfig /renew를 입력해 새로운 IP를 할당받고 netsh winsock reset을 쳐서 소켓을 초기화합니다. 모든 명령어가 끝난 뒤 컴퓨터를 재부팅하여 네트워크 연결 상태를 테스트합니다.

## 윈도우 네트워크 및 인터넷 문제 해결사 실행

윈도우 설정 앱의 네트워크 및 인터넷 메뉴로 들어가서 문제 해결 도구를 찾습니다. 윈도우 시스템이 자동으로 랜카드, 와이파이, IP 설정을 스캔하여 문제점을 진단해 줍니다. 발견된 오류에 대해 시스템이 자동으로 수정을 시도하므로 지시에 따릅니다. 사용자가 직접 원인을 찾기 힘들 때 가장 쉽고 빠르게 시도할 수 있는 내장 기능입니다.

## 랜카드 하드웨어 고장 시 외장 랜카드 대안

위의 모든 소프트웨어적 조치와 랜선 교체에도 반응이 없다면 메인보드 내장 랜카드 고장을 의심해야 합니다. 메인보드 AS를 받거나 수리가 번거롭다면 USB 포트에 꽂아 쓰는 외장 랜카드를 구매해 해결합니다. 저렴한 비용으로 간단히 유선 인터넷이나 무선 와이파이 기능을 부활시킬 수 있는 현실적 대안입니다.

랜선 연결과 와이파이가 동시에 안 될 때는 공유기 재부팅과 랜카드 드라이버 점검이 우선입니다. 하드웨어 고장 여부까지 차근차근 확인해 보세요.
