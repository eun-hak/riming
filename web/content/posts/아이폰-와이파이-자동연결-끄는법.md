아이폰 와이파이 자동연결 끄는법은 iOS 설정 메뉴에서 특정 네트워크의 자동 연결 기능을 비활성화하는 방식으로 진행합니다. 공공 와이파이나 불안정한 네트워크가 자동으로 잡히는 것이 불편하다면 이 설정을 통해 제어할 수 있습니다. 사용자가 원하지 않는 와이파이에 연결되지 않도록 관리하는 것은 개인정보 보호와 데이터 절약에도 큰 도움이 됩니다.

## 특정 와이파이 자동 연결 해제하기

설정 앱에서 와이파이 메뉴로 들어간 뒤, 자동 연결을 끄고 싶은 네트워크 옆의 파란색 정보 아이콘을 누릅니다. 해당 네트워크의 상세 정보 화면에서 자동 연결 항목을 찾아 스위치를 끕니다. 이렇게 설정하면 해당 네트워크 범위 내에 있더라도 아이폰이 자동으로 연결을 시도하지 않습니다. 다시 연결하고 싶을 때는 수동으로 와이파이 목록에서 선택하면 됩니다. 필요한 경우에만 선택적으로 연결하여 네트워크를 관리하십시오.

## 네트워크 자체를 완전히 삭제하는 방법

더 이상 연결할 의사가 없는 와이파이 네트워크는 아예 기록에서 지울 수 있습니다. 와이파이 목록에서 네트워크 정보 화면으로 진입한 뒤 이 네트워크 지우기를 선택합니다. 이렇게 하면 아이폰이 해당 네트워크를 기억하지 않으므로 자동 연결될 가능성이 완전히 사라집니다. 다시 연결하려면 비밀번호를 새로 입력해야 하므로 보안 측면에서도 효과적입니다. 불필요한 네트워크 기록을 주기적으로 정리하는 습관을 가져보십시오.

## 아이폰 와이파이 자동 검색 비활성화

와이파이를 아예 끄고 싶다면 제어 센터나 설정에서 와이파이 스위치를 비활성화하십시오. 단 제어 센터에서 끄는 것은 일시적인 연결 해제일 뿐 다음 날 아침이나 새로운 장소로 이동하면 다시 켜질 수 있습니다. 완전히 끄려면 설정 앱의 와이파이 메뉴에서 직접 스위치를 내려야 합니다. 특정 장소에서 와이파이 간섭을 피하고 싶을 때 이 방법을 사용합니다. 데이터 사용을 원할 때만 다시 켜서 활용하십시오.
