## 카카오톡 대화 백업 기능의 기본 조건

카카오톡 대화 백업은 앱 내 설정 메뉴를 통해 수동으로 진행해야 하며 자동 백업은 지원되지 않습니다. 백업된 데이터는 카카오 서버에 암호화되어 최대 14일 동안만 보관됩니다. 이 기간 내에 새 기기에서 동일한 카카오계정으로 로그인하여 복원을 완료해야 합니다. 미디어 파일은 백업 대상에 포함되지 않으므로 중요한 사진은 개별 저장해야 합니다.

## 실제 대화 내용 백업 진행 순서

카카오톡 앱을 실행한 후 우측 상단의 톱니바퀴 모양 설정 아이콘을 터치하여 전체 설정으로 진입합니다. 채팅 메뉴를 선택한 뒤 대화 백업 항목을 누르고 대화 백업하기 버튼을 실행합니다. 백업 과정에서 사용할 비밀번호를 설정하고 입력하면 서버로 데이터 전송이 시작됩니다. 백업 완료 화면에 나타나는 만료일을 반드시 확인해 두어야 합니다.

## 새 기기에서 백업 데이터 복원하기

새로운 스마트폰에 카카오톡을 설치한 후 이전과 동일한 카카오계정 전화번호로 로그인합니다. 본인 인증 과정을 거치면 백업된 데이터가 있는지 자동으로 감지하여 복원 화면이 나타납니다. 백업할 때 설정했던 비밀번호를 정확히 입력해야 데이터 압축 해제가 진행됩니다. 복원이 완료될 때까지 앱을 끄지 말고 대기해야 오류를 방지할 수 있습니다.

대화 백업에 포함되지 않는 사진과 동영상은 각 채팅방의 미디어 파일함에서 개별적으로 백업해야 합니다. 중요한 사진은 스마트폰의 기본 갤러리나 클라우드 서비스로 내보내기 기능을 사용해 저장합니다. 오픈채팅방의 데이터는 백업 기능이 지원되지 않으므로 필요한 내용을 미리 캡처해 두어야 합니다. 대화창에 남아있는 파일은 기간이 지나면 만료되므로 수시로 백업하는 것이 안전합니다.
