스마트폰을 새로 교체하거나 기기를 변경할 때 그동안 열심히 건설하고 플레이했던 마인크래프트 모바일 세계관과 데이터를 어떻게 옮겨야 할지 막막합니다. 마인크래프트 포켓 에디션은 저장 위치에 따라 파일 관리 앱을 통해 수동으로 백업하고 이동해야 안전하게 세이브파일을 보존할 수 있습니다. 안드로이드 기기 간에 마인크래프트 세계를 손실 없이 옮기는 구체적인 방법을 안내합니다.

## 마인크래프트 파일 저장 위치 이해하기

안드로이드 스마트폰에서 마인크래프트 모바일의 월드 세이브 데이터는 기본적으로 내부 저장소의 특정 폴더에 저장됩니다. 과거에는 외장 경로에 바로 노출되었으나 최신 안드로이드 버전을 탑재한 기기에서는 보안 정책으로 인해 접근 경로가 조금 까다로워졌습니다. 내장된 기본 파일 관리자 앱이나 별도의 파일 탐색기 앱을 사용하여 저장소 경로로 진입해야 합니다. 정확한 기본 경로는 games/com.mojang/minecraftWorlds 폴더이며 이곳에 개별 월드들이 폴더 형태로 들어 있습니다.

## 기존 스마트폰에서 월드 폴더 백업하기

기존에 사용하던 스마트폰에서 파일 관리자 앱을 실행하고 내부 저장소로 이동합니다. games 폴더를 열고 com.mojang 폴더를 거쳐 minecraftWorlds 폴더 내부로 진입합니다. 그 안에 무작위 영문과 숫자로 이루어진 폴더들이 각각 개별 월드 세이브 데이터에 해당합니다. 옮기고 싶은 월드 폴더를 길게 눌러 선택한 뒤 압축(ZIP) 파일로 변환하거나 외장 SD카드 혹은 클라우드에 업로드합니다.

## 새 스마트폰으로 파일 전송 및 위치시키기

백업해 둔 월드 폴더나 압축 파일을 구글 드라이브, 카카오톡 내 파일 또는 스마트스위치 등을 이용해 새 스마트폰으로 보냅니다. 새 스마트폰에서도 동일하게 내부 저장소의 games/com.mojang/minecraftWorlds 경로로 이동합니다. 만약 새 폰에 해당 폴더가 없다면 마인크래프트를 한 번 실행했다가 종료하면 자동으로 생성됩니다. 전송받은 월드 폴더를 그 경로 안에 정확히 압축을 풀거나 복사해 넣습니다.

## 안드로이드 11 이상 버전 파일 접근 주의사항

최신 안드로이드 버전을 사용하는 스마트폰에서는 보안 앱 권한 문제로 기본 파일 앱에서 com.mojang 폴더 접근이 막혀 있을 수 있습니다. 이때는 구글 플레이스토어에서 'ZAArchiver' 같은 권한 설정이 자유로운 서드파티 파일 탐색기 앱을 다운로드하여 사용합니다. 해당 앱을 통해 내부 저장소의 Android/data 폴더나 games 폴더로 안전하게 접근할 수 있습니다. 앱 실행 시 파일 접근 권한을 허용해 주어야 원활한 작업이 가능합니다.

## 리소스 팩 및 스킨 데이터 함께 옮기기

월드 세이브 데이터 외에도 그동안 다운로드한 리소스 팩, 행동 팩, 커스텀 스킨도 함께 옮겨야 완벽한 이전이 됩니다. com.mojang 폴더 안에는 resource_packs, behavior_packs, skin_packs 등 각각의 폴더가 따로 존재합니다. 필요한 팩 폴더들을 동일한 방식으로 압축하여 새 스마트폰의 각각의 위치에 맞게 복사해 넣습니다. 게임을 실행한 후 설정의 리소스 팩 메뉴에서 정상적으로 적용되었는지 최종 확인합니다.

## 게임 실행 후 월드 로딩 상태 최종 확인

모든 파일 이동 작업을 마친 뒤 새 스마트폰에서 마인크래프트 앱을 실행합니다. 플레이 버튼을 눌러 세계 목록에 이전한 월드가 정상적으로 나타나는지 확인합니다. 월드에 직접 접속하여 건축물과 인벤토리 아이템이 유실되지 않고 잘 불러와졌는지 꼼꼼히 체크합니다. 파일 이동 중 경로가 잘못되었거나 압축 해제가 누락되면 게임에서 월드를 인식하지 못하므로 경로를 재차 확인합니다.

마인크래프트 모바일 데이터 이동은 minecraftWorlds 폴더를 정확히 찾아 백업하고 복사하는 것이 핵심입니다. 위 절차를 천천히 따라 하셔서 소중한 월드를 안전하게 옮기시기 바랍니다.
