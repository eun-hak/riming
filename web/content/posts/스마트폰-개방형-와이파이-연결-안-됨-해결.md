공공장소에서 제공하는 개방형 와이파이에 스마트폰이 연결되지 않는다면, 인증 페이지가 뜨지 않거나 신호 충돌이 발생하는 경우가 많습니다. 개방형 와이파이는 보안이 없는 대신 웹 브라우저를 통한 인증 과정이 필수입니다. 하지만 스마트폰이 이를 인식하지 못하면 연결은 되어도 인터넷이 차단됩니다.

## 인증 페이지 강제 호출하기

개방형 와이파이에 연결해도 인터넷이 안 된다면 브라우저를 열고 아무 사이트나 접속해 보십시오. 그러면 자동으로 인증 페이지로 리다이렉트되는 경우가 많습니다. 만약 리다이렉트가 안 된다면 '1.1.1.1'이나 'never.com' 같이 간단한 주소를 직접 입력하여 인증 화면을 강제로 띄워야 합니다. 인증 페이지에서 이용 동의를 클릭해야 인터넷 사용 권한이 부여됩니다. 보안 DNS 설정이 이를 방해하는 경우도 있으니 확인하십시오.

## 개인 DNS 설정 확인하기

스마트폰 설정에서 '개인 DNS'를 사용 중이라면 개방형 와이파이 인증이 실패할 수 있습니다. 설정의 네트워크 메뉴에서 개인 DNS를 '자동' 또는 '끄기'로 변경해 보십시오. 사설 DNS 서버가 인증 페이지로의 접속을 차단하는 경우가 많기 때문입니다. 와이파이 사용이 끝난 후 다시 원래대로 설정하면 됩니다. 개방형 네트워크에서는 기본 DNS 설정을 사용하는 것이 가장 안정적입니다.

## 와이파이 네트워크 삭제 후 재연결

이전에 해당 와이파이에 연결했던 기록이 꼬여서 문제가 발생할 수 있습니다. 와이파이 설정에서 해당 네트워크를 '네트워크 삭제'하거나 '지우기'를 선택하십시오. 완전히 정보를 지운 뒤 다시 연결을 시도하면 인증 과정을 처음부터 다시 거치게 됩니다. 이 과정에서 기존의 잘못된 인증 토큰이 정리됩니다. 다시 연결할 때 팝업창이 뜨는지 주의 깊게 확인하십시오.

## MAC 주소 무작위 설정 변경

최신 스마트폰은 보안을 위해 MAC 주소를 무작위로 생성합니다. 하지만 일부 개방형 와이파이는 기기를 식별하기 위해 고정된 MAC 주소를 요구하기도 합니다. 와이파이 상세 설정에서 'MAC 주소 유형'을 '휴대전화 MAC'으로 변경해 보십시오. 이렇게 하면 고유 주소를 사용하여 네트워크 인증을 받을 수 있습니다. 변경 후에는 다시 연결을 시도하여 인증이 정상적으로 이루어지는지 확인합니다.

## 신호 간섭 및 위치 서비스 점검

주변에 사람이 너무 많아 와이파이 신호가 포화 상태일 수 있습니다. 이럴 때는 잠시 자리를 옮기거나 와이파이를 껐다 켜보십시오. 안드로이드 기기의 경우 와이파이 검색 기능을 향상시키기 위해 위치 서비스를 사용하는 경우가 많습니다. 위치 권한이 켜져 있는지 확인하고 다시 시도하십시오. 기기가 주변 네트워크를 더 정확하게 스캔하여 연결을 원활하게 돕습니다.

## 공공 와이파이 서비스 자체 점검

위의 모든 방법을 써도 안 된다면 와이파이 서비스 자체의 문제일 확률이 높습니다. 공공 와이파이 기기가 과부하되거나 인터넷 회선이 끊긴 상태일 수 있습니다. 다른 사람들의 스마트폰도 연결되지 않는다면 서비스 제공 측의 문제이므로 해결을 기다려야 합니다. 혹은 너무 많은 기기가 접속하여 새로운 접속을 차단하고 있을 수 있습니다. 가급적 사람이 적은 시간대나 위치를 이용하는 것이 좋습니다.

인증 페이지를 강제로 띄우는 것이 가장 확실한 방법입니다. 개인 DNS 설정을 확인하고 네트워크를 지운 뒤 다시 시도하여 개방형 와이파이 연결 문제를 해결하시기 바랍니다.
