닌텐도 스위치 와이파이 연결은 본체 설정 메뉴의 인터넷 항목에서 간단히 수행할 수 있습니다. 무선 네트워크를 검색하고 올바른 비밀번호를 입력하면 즉시 온라인 기능을 사용할 수 있습니다. 만약 연결이 실패한다면 공유기와의 거리나 주파수 대역 설정을 확인해야 합니다. 온라인 접속이 되지 않을 때 시도해 볼 수 있는 기본적인 네트워크 설정법을 안내합니다.

## 무선 네트워크 연결 절차

홈 화면에서 설정 메뉴로 들어간 뒤 인터넷 항목을 선택합니다. 인터넷 설정 버튼을 누르면 주변의 무선 네트워크를 자동으로 검색합니다. 리스트에서 본인의 와이파이 이름을 찾아 선택합니다. 비밀번호가 설정되어 있다면 키보드가 나타나며 입력을 요구합니다. 올바르게 입력한 뒤 연결 테스트를 진행하여 성공 문구가 뜨면 완료됩니다.

## 5GHz와 2.4GHz 주파수 선택

닌텐도 스위치는 2.4GHz와 5GHz 대역을 모두 지원합니다. 공유기와의 거리가 가깝다면 전송 속도가 빠른 5GHz를 권장합니다. 반면 방을 넘어가거나 거리가 멀다면 안정적인 2.4GHz를 선택하는 것이 좋습니다. 연결이 자꾸 끊긴다면 다른 주파수 대역으로 전환하여 시도해 봅니다. 공유기 설정에서 두 대역의 이름을 다르게 설정하면 구분이 쉽습니다.

## 연결 오류 발생 시 조치 사항

연결이 실패했다는 메시지가 나오면 가장 먼저 공유기를 재부팅합니다. 전원을 완전히 껐다가 1분 뒤 다시 켜는 것만으로도 대부분의 일시적 오류가 해결됩니다. 본체 설정에서 인터넷 설정을 삭제하고 다시 등록하는 과정도 효과적입니다. 공유기의 비밀번호가 변경되었는지 확인하고 최신 보안 규격인 WPA2/WPA3가 적용되었는지 체크합니다.

## DNS 설정 변경으로 속도 개선

연결은 되어 있으나 속도가 느리거나 접속이 원활하지 않을 때 DNS 설정을 수정합니다. 설정 내 인터넷 연결 상세 정보에서 DNS 설정을 수동으로 변경합니다. 일반적으로 구글 DNS인 8.8.8.8과 8.8.4.4를 입력하여 테스트합니다. 이를 통해 네트워크 경로가 최적화되어 다운로드 속도가 향상될 수 있습니다. 단 이 방법은 환경에 따라 효과가 다를 수 있습니다.

## 공공 와이파이 이용 시 주의점

카페나 공공장소의 와이파이는 웹 페이지 인증이 필요한 경우가 많습니다. 닌텐도 스위치에서는 이러한 웹 인증 과정을 수행하기 어렵습니다. 따라서 공공 와이파이 사용 시 연결이 제한될 수 있음을 인지해야 합니다. 원활한 게임 플레이를 위해서는 가정용 무선 공유기를 사용하거나 스마트폰 핫스팟을 이용하는 것이 좋습니다. 핫스팟 이용 시 데이터 사용량을 주의하십시오.

## NAT 타입 확인 및 최적화

멀티플레이 게임 도중 오류가 발생한다면 NAT 타입이 원인일 수 있습니다. 설정 내 연결 테스트 결과에서 NAT 타입이 A나 B로 표시되는 것이 가장 좋습니다. 만약 D나 F라면 공유기 설정에서 포트 포워딩이나 DMZ 설정을 수행해야 합니다. 이는 네트워크 지식이 다소 필요하므로 공유기 제조사의 매뉴얼을 참조해야 합니다. 일반적인 가정 환경이라면 대부분 자동으로 적절하게 잡힙니다.

닌텐도 와이파이 연결은 공유기 재부팅과 주파수 선택으로 대부분 해결됩니다. 설정 메뉴를 통해 네트워크 상태를 상시 확인하십시오.
