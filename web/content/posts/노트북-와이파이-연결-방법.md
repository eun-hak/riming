새로 구매한 노트북이나 포맷을 마친 노트북에서 무선 인터넷을 사용하기 위해 와이파이를 연결하는 방법을 찾게 됩니다. 윈도우 운영체제 버전별로 약간의 차이는 있지만 전체적인 무선 네트워크 연결 과정은 매우 직관적이고 간단합니다. 올바른 랜카드 드라이버가 설치되어 있다면 몇 번의 클릭만으로 주변 무선 신호를 잡아 인터넷을 쓸 수 있습니다. 지금부터 노트북에 와이파이를 연결하는 구체적인 설정 순서와 주의사항을 설명해 드리겠습니다.

## 작업 표시줄에서 와이파이 아이콘 찾기

노트북 화면 우측 하단의 작업 표시줄에서 네트워크 또는 와이파이 모양의 아이콘을 찾습니다. 만약 해당 아이콘이 보이지 않는다면 아직 무선 랜카드 드라이버가 설치되지 않았거나 기능이 꺼진 상태입니다. 윈도우 설정 메뉴의 네트워크 및 인터넷 항목으로 진입하여 와이파이 스위치가 켬으로 되어 있는지 확인합니다. 노트북 측면이나 키보드 상단에 물리적인 무선 랜 전원 스위치나 단축키가 있는 경우 이를 켜주어야 합니다. 정상적으로 활성화되면 주변에서 잡히는 무선 네트워크 목록이 화면에 나타나기 시작합니다.

## 사용할 무선 공유기 네트워크 선택하기

와이파이 아이콘을 클릭하여 나타난 연결 가능한 네트워크 목록에서 본인이 사용하려는 공유기 이름을 찾습니다. 가정에서 사용하는 경우 공유기 하단이나 측면에 기재된 SSID 이름과 동일한 것을 선택합니다. 공공장소나 카페인 경우 해당 매장에서 제공하는 공식 와이파이 이름을 정확히 확인한 후 클릭합니다. 목록에 원하는 신호가 뜨지 않는다면 공유기 전원을 재부팅하거나 노트북을 공유기 가까운 곳으로 이동해 봅니다. 신호 세기가 충분히 확보된 상태에서 연결 버튼을 누르는 것이 접속 오류를 줄이는 요령입니다.

## 보안 키 및 와이파이 비밀번호 입력하기

보안이 설정된 와이파이를 선택하면 네트워크 보안 키를 입력하라는 입력창이 화면에 팝업으로 뜹니다. 공유기 뒷면에 적혀 있는 영문과 숫자로 조합된 암호를 오타 없이 정확하게 입력합니다. 대소문자를 구분하므로 스마트폰 카메라로 미리 촬영해 두고 확인하며 입력하면 실수를 줄일 수 있습니다. 비밀번호를 입력한 후 다음 단계를 누르면 노트북이 해당 공유기와 인증 과정을 거치게 됩니다. 암호가 틀렸다는 문구가 뜬다면 비밀번호를 다시 한번 대조하여 정확히 입력해 줍니다.

## 자동 연결 설정 및 공용 네트워크 지정

비밀번호 인증이 완료되면 앞으로 해당 장소에 있을 때 자동으로 연결되도록 설정하는 옵션을 체크합니다. 가정이나 개인 사무실인 경우 네트워크에 연결된 다른 기기들이 이 PC를 검색할 수 있도록 허용합니다. 반면 카페나 도서관 같은 공공장소의 와이파이인 경우 보안을 위해 공용 네트워크로 지정하는 것이 안전합니다. 최초 연결 설정이 올바르게 완료되면 작업 표시줄의 아이콘이 부채꼴 모양으로 바뀌며 인터넷 접속이 가능해집니다. 이후부터는 부팅 시 자동으로 무선 인터넷에 원활하게 접속됩니다.

## 무선 랜카드 드라이버 미설치 시 대처법

와이파이 목록 자체가 아예 뜨지 않거나 어댑터가 활성화되지 않는다면 랜카드 드라이버 문제일 수 있습니다. 제조사 홈페이지에서 해당 노트북 모델명에 맞는 최신 무선 랜 드라이버를 유선 인터넷이나 USB를 통해 다운로드합니다. 다운로드한 설치 파일을 실행하여 드라이버를 정상적으로 설치한 후 노트북을 재부팅해 줍니다. 장치 관리자에서 네트워크 카드에 노란색 느낌표가 뜨는지 확인하고 올바른 드라이버를 다시 잡아줍니다. 드라이버가 정상 작동하면 비로소 와이파이 검색 기능이 활성화됩니다.

## 연결 후 인터넷 끊김 현상 점검 요령

와이파이는 연결되었다고 뜨지만 수시로 인터넷이 끊기거나 속도가 너무 느린 경우가 발생할 수 있습니다. 이럴 때는 공유기와의 거리가 너무 멀거나 장애물이 많지 않은지 주변 환경을 점검합니다. 채널 간섭이 심한 경우 공유기 설정 페이지에 접속해 와이파이 채널을 변경해 주는 것이 도움이 됩니다. 지속적으로 문제가 해결되지 않는다면 네트워크 초기화 기능을 실행하여 설정을 처음부터 다시 세팅합니다.

노트북 와이파이 연결은 작업 표시줄에서 네트워크를 선택하고 올바른 비밀번호를 입력하면 간단히 끝납니다. 드라이버 상태를 점검하여 안정적인 무선 인터넷 환경을 구축하시기 바랍니다.
