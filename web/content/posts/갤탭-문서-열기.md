갤럭시 탭에서 문서를 열 때 나타나는 '항상 사용'과 '한 번만 사용' 설정 때문에 불편을 겪는 경우가 종종 발생합니다. 이 설정은 앱의 기본 실행 동작을 결정하는 것으로, 실수로 '항상 사용'을 선택했더라도 간단한 조작으로 초기화할 수 있습니다. 특정 앱이 기본값으로 고정되어 다른 앱으로 파일을 열 수 없을 때 해결하는 방법을 정리했습니다.

## 기본 앱 설정 초기화 원리

안드로이드 시스템은 특정 파일을 열 때 사용자가 선택한 앱을 기억하는 기능을 갖추고 있습니다. '항상 사용'을 누르면 해당 파일 형식이 항상 그 앱에서 열리도록 시스템이 자동으로 지정합니다. 이를 되돌리려면 앱 정보 메뉴에 들어가서 기본 설정 값을 삭제해야 합니다. 이 작업은 기기 내의 데이터를 삭제하는 것이 아니라 연결 방식만 초기화하는 것입니다. 안심하고 설정을 변경해도 됩니다.

## 설정 메뉴 진입하기

갤럭시 탭의 설정 앱을 실행한 후 애플리케이션 항목으로 이동합니다. 기기에 설치된 모든 앱 목록이 나타나면 여기서 기본 앱으로 설정되어 있는 앱을 찾습니다. 예를 들어 한글 문서를 열 때 항상 열리는 앱이 있다면 해당 앱을 목록에서 선택하십시오. 앱 정보를 클릭하면 하단이나 중간에 기본으로 설정됨이라는 문구가 표시됩니다. 이를 클릭하여 상세 설정 화면으로 넘어갑니다.

## 기본 설정 삭제 실행

기본 설정 항목 안에 들어가면 '기본 설정 삭제'라는 버튼을 확인할 수 있습니다. 이 버튼을 누르면 해당 앱이 특정 파일 형식에 대해 기본적으로 실행되도록 지정된 정보가 해제됩니다. 이제 다시 문서를 열려고 시도하면 다시 '한 번만 사용' 또는 '항상 사용'을 선택하는 창이 나타납니다. 여기서 상황에 맞게 원하는 선택지를 고르면 됩니다. 다시는 이전의 고정된 설정이 적용되지 않습니다.

## 파일 선택 창 다시 띄우기

설정을 초기화한 뒤 문서를 다시 클릭하면 시스템이 다시 연결 프로그램을 묻습니다. 이때 다시 '항상 사용'을 선택하면 앞으로 해당 파일은 무조건 그 앱에서 열리게 됩니다. 특정 파일 형식을 매번 다른 앱으로 열어야 한다면 반드시 '한 번만 사용'을 선택하는 습관을 들이는 것이 좋습니다. 매번 선택하는 것이 번거롭더라도 상황에 따라 유연하게 대처할 수 있는 장점이 있습니다. 이 과정은 언제든지 반복 가능합니다.

## 특정 앱이 보이지 않는 경우

만약 목록에서 원하는 앱을 찾을 수 없다면 '앱 설정' 내의 필터를 확인해야 합니다. 시스템 앱까지 모두 표시하도록 설정하면 숨겨진 앱들도 목록에 나타납니다. 간혹 앱 업데이트 후 설정이 꼬이는 경우가 있는데 이럴 때는 앱을 삭제했다가 다시 설치하는 것도 방법입니다. 하지만 기본 설정 초기화만으로 대부분의 문제는 해결됩니다. 설정 메뉴를 꼼꼼히 살펴보며 기본 앱 연결 상태를 점검하십시오.

## 앱별 기본 설정 관리의 장점

문서 작업이 많은 경우 앱마다 용도를 나누어 활용하는 것이 효율적입니다. 예를 들어 수정은 한컴 오피스에서, 단순 뷰어는 삼성 노트에서 여는 식으로 분리할 수 있습니다. 기본 설정을 자유롭게 변경할 수 있으면 갤럭시 탭의 활용도가 훨씬 높아집니다. 사용자 환경에 맞게 앱을 최적화하여 문서 생산성을 극대화해 보시기 바랍니다. 꾸준히 관리하면 기기를 더욱 쾌적하게 사용할 수 있습니다.

갤럭시 탭의 기본 앱 설정은 설정 메뉴 내 애플리케이션 항목에서 손쉽게 초기화할 수 있습니다. 이제 원하는 앱으로 문서를 자유롭게 열어보시기 바랍니다. 추가적인 기기 오류가 발생하면 제조사의 고객 센터를 통해 지원을 받으십시오.
