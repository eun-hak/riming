가정에서 흔히 사용하는 아이피타임 공유기에 갑자기 불이 들어오지 않거나 와이파이가 연결되지 않는 문제가 발생합니다. 랜선 접촉 불량부터 공유기 내부 설정 오류, 통신사 모뎀 신호 이상까지 원인은 다양하게 존재합니다. 무작정 방치하기보다 각 부위의 LED 상태등을 보며 차근차근 점검하는 것이 빠른 해결의 지름길입니다. 지금부터 아이피타임 와이파이 공유기 연결 오류를 해결하는 구체적인 방법을 알아봅니다.

## 공유기 전원 및 LED 상태등 확인하기

공유기 본체에 전원 어댑터가 단단히 꼽혀 있고 전면 LED 불빛이 정상적으로 들어오는지 봅니다. 전원 불빛이 아예 들어오지 않는다면 어댑터 고장이나 멀티탭 전원 이상을 의심해야 합니다. CPU 램프가 일정한 주기로 깜빡여야 공유기 내부 시스템이 정상 작동하는 상태입니다. 인터넷 포트와 연결된 랜선 포트의 불빛 점멸 상태도 함께 확인합니다.

## 통신사 모뎀과 공유기 간 랜선 연결 점검

벽면 단자나 통신사 모뎀에서 나온 인터넷 선이 공유기의 WAN 포트에 정확히 꽂혀 있는지 봅니다. 공유기의 나머지 LAN 포트들은 PC나 다른 기기로 향하는 선이므로 포트 위치가 바뀌면 안 됩니다. 랜선을 뽑았다가 딸깍 소리가 나도록 다시 깊숙이 체결합니다. 랜선 자체의 단선 여부를 알기 위해 다른 여분의 케이블로 교체해 봅니다.

## 공유기 및 모뎀 전원 재부팅 순서 지키기

네트워크 장비에 오류가 생겼을 때는 올바른 순서로 전원을 껐다 켜야 합니다. 먼저 통신사 모뎀과 아이피타임 공유기의 전원선을 모두 분리합니다. 모뎀의 전원을 먼저 켜고 완전히 부팅될 때까지 2분 정도 기다립니다. 그 후 공유기 전원을 켜고 네트워크 신호가 안정화되기를 기다립니다.

## 스마트폰이나 PC로 공유기 관리자 페이지 접속

물리적 연결에 이상이 없다면 관리자 페이지에 접속하여 내부 설정을 점검합니다. 와이파이 연결이 가능한 기기로 아이피타임 무선 신호나 유선 랜선에 붙습니다. 인터넷 주소창에 기본 IP 주소를 입력하여 로그인 화면으로 진입합니다. 초기 설정된 관리자 계정으로 접속하여 인터넷 연결 상태를 모니터링합니다.

## 공유기 내부 설정 초기화 리셋 버튼 누르기

관리자 페이지 로그인이 안 되거나 설정이 심하게 꼬인 경우 공장 초기화를 진행합니다. 공유기 후면에 작은 구멍으로 되어 있는 RST 리셋 버튼을 찾습니다. 전원이 켜진 상태에서 뾰족한 도구로 버튼을 10초 이상 길게 누릅니다. 모든 LED가 깜빡이며 초기화되면 와이파이 이름과 비밀번호를 처음부터 다시 설정합니다.

## 통신사 고객센터로 인터넷 회선 신호 문의

공유기와 모뎀을 모두 재부팅하고 초기화했음에도 인터넷 불빛이 들어오지 않는 상황입니다. 이는 공유기 자체의 고장일 수도 있지만 통신사 외부 회선 자체에 문제가 생긴 경우입니다. 사용 중인 인터넷 통신사 고객센터에 연락하여 외부 선로 신호 이상 여부를 점검받습니다. 필요시 기사 방문을 요청하여 장비를 교체해야 합니다.

아이피타임 공유기 연결 오류는 모뎀과 공유기의 전원 재부팅만으로도 대부분 정상화됩니다. 지속적인 문제가 발생한다면 리셋을 통한 공장 초기화나 통신사 회선 점검을 진행하시기 바랍니다.
