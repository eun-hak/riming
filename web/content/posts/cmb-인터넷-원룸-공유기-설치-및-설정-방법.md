CMB 인터넷을 이용하는 원룸에서 공유기를 설치할 때는 통신사의 모뎀 방식에 따라 설정이 다를 수 있습니다. 대부분의 공유기는 자동으로 설정되지만, 특정 환경에서는 수동 세팅이 필요합니다. 원활한 인터넷 사용을 위한 설치 가이드를 정리했습니다.

## 벽면 랜 포트와 공유기 연결 확인

원룸 환경에서는 벽면의 랜 포트에서 직접 선을 가져오는 경우가 많습니다. 이 선을 공유기의 WAN 포트에 연결하십시오. 공유기 뒷면의 색상이 다른 포트가 WAN 포트입니다. 공유기 전원을 켜고 전면의 LED 상태를 확인하십시오. 인터넷 표시등이 정상적으로 들어오는지 보는 것이 첫 번째입니다. 만약 인터넷 표시등이 들어오지 않는다면 벽면 포트 자체의 신호를 점검해야 합니다. 건물 관리실에 문의하여 해당 호실의 인터넷 회선이 활성화되어 있는지 확인하십시오. 기본 연결이 되어야 다음 단계 설정이 가능합니다.

## 자동 IP 할당과 공유기 기본 설정

대부분의 공유기는 연결만 하면 자동으로 인터넷을 인식합니다. 컴퓨터나 스마트폰을 공유기 와이파이에 연결하고 웹 브라우저를 실행하십시오. 별도의 설정 없이 바로 인터넷이 된다면 추가 조치는 필요 없습니다. 만약 연결은 되는데 인터넷이 안 된다면 공유기 관리자 페이지에 접속해야 합니다. 192.168.0.1 또는 해당 브랜드의 주소를 입력하십시오. 초기 아이디와 비밀번호는 설명서를 참고하거나 공유기 하단 스티커를 확인하십시오. 자동 할당된 IP를 공유기가 인식하고 있는지 상태창에서 체크하십시오.

## CMB 통신사 환경의 고정 IP 설정

일부 원룸 지역의 CMB 인터넷은 고정 IP를 요구할 수 있습니다. 이 경우 관리자 페이지의 인터넷 설정 메뉴에서 IP 주소 방식을 고정으로 변경하십시오. 통신사에서 제공받은 IP 주소, 서브넷 마스크, 기본 게이트웨이, DNS 서버 정보를 입력해야 합니다. 이 정보는 계약서나 설치 기사님께 받은 안내문에 적혀 있습니다. 정보를 잘못 입력하면 인터넷이 연결되지 않으니 정확하게 기입하십시오. 고정 IP 설정은 원룸 인터넷 환경에서 자주 발생하는 연결 오류를 해결하는 핵심입니다. 정보가 없다면 CMB 고객센터에 문의하십시오.

## 공유기 이름과 와이파이 비밀번호 보안

공유기를 설치한 후에는 반드시 와이파이 비밀번호를 설정해야 합니다. 보안 설정이 되어 있지 않으면 주변 사람들이 내 인터넷을 무단으로 사용할 수 있습니다. 관리자 페이지의 무선 설정 메뉴에서 네트워크 이름을 지정하고 비밀번호를 강력하게 설정하십시오. 보안 설정을 해야 속도 저하를 막고 개인정보를 보호할 수 있습니다. 변경 후에는 모든 기기에서 다시 와이파이를 연결해야 합니다. 주기적으로 비밀번호를 바꾸는 것도 좋은 습관입니다.

## 원룸 인터넷 속도 저하 시 점검 사항

원룸은 여러 세대가 인터넷 회선을 공유하는 경우가 많아 속도가 느려질 수 있습니다. 공유기 설정에서 채널을 변경하면 간섭을 줄여 속도를 개선할 수 있습니다. 2.4GHz와 5GHz 대역 중 속도가 더 빠른 5GHz를 우선적으로 사용하십시오. 공유기를 너무 구석진 곳이나 가전제품 근처에 두지 말고 개방된 곳에 배치하십시오. 공유기 내부의 펌웨어를 최신으로 업데이트하는 것도 속도 향상에 도움이 됩니다. 공유기의 발열이 심하면 성능이 떨어지므로 공기 순환이 잘 되는 곳에 두십시오. 작은 배치 변화가 속도에 큰 차이를 만듭니다.

## 다중 기기 접속 시 공유기 부하 관리

많은 기기를 동시에 연결하면 공유기에 부하가 걸려 인터넷이 끊길 수 있습니다. 관리자 페이지에서 연결된 기기 목록을 확인하고 불필요한 기기는 연결을 해제하십시오. 공유기의 재부팅 주기를 설정하여 시스템의 안정성을 유지하십시오. 고성능 공유기가 아니라면 기기 연결 개수를 제한하는 것도 방법입니다. 원룸에서 기기를 많이 사용한다면 기가비트 지원 공유기를 사용하는 것이 훨씬 유리합니다. 공유기 성능은 기기 연결 수와 비례합니다. 쾌적한 사용 환경을 위해 네트워크 사용량을 주기적으로 점검하십시오.

## 고객센터 문의 및 회선 점검 요청

공유기 설정이 모두 정확한데도 인터넷이 안 된다면 통신사 회선 문제입니다. CMB 고객센터에 전화하여 해당 호실의 인터넷 신호를 점검해 달라고 요청하십시오. 모뎀 자체의 고장일 수도 있으므로 기사님 방문 점검이 필요할 수 있습니다. 공유기를 연결하기 전 벽면 포트에 직접 PC를 연결하여 테스트해 보십시오. 직접 연결해도 안 된다면 공유기 문제가 아니라 통신사 문제임이 확실합니다. 이 정보를 상담원에게 알려주면 처리가 훨씬 빨라집니다. 전문가의 도움을 받는 것이 가장 빠르고 정확한 해결책입니다.

원룸 인터넷은 회선 방식에 따라 설정이 다를 수 있습니다. 자동 설정이 안 된다면 고정 IP 정보를 확인하여 수동으로 세팅해 보시기 바랍니다.
