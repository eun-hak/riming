갤럭시 스마트폰의 설정 메뉴에서 제공하는 디지털 웰빙 기능은 앱 사용 시간과 잠금 해제 횟수를 기록합니다. 개인적인 이유나 필요에 따라 이러한 사용 시간 기록을 삭제하거나 초기화하고 싶어 하는 사용자들이 많습니다. 안드로이드 시스템 구조상 사용 시간 통계 데이터를 사용자가 직접 선택하여 특정 날짜만 지우는 것은 기본적으로 지원되지 않습니다. 그러나 관련 앱의 데이터를 초기화하거나 기능을 끄는 방식으로 기록을 관리할 수 있습니다.

## 디지털 웰빙 기능의 작동 방식 이해

갤럭시의 디지털 웰빙은 백그라운드에서 사용자의 스마트폰 사용 패턴을 실시간으로 수집하여 통계로 보여줍니다. 이 데이터는 스마트폰 내부 저장소의 시스템 앱 데이터 영역에 안전하게 누적됩니다. 특정 앱을 얼마나 켰는지, 화면을 몇 번이나 켰는지에 대한 정보가 자동으로 기록되는 구조입니다. 사용자가 임의로 특정 앱의 기록만 골라서 삭제하는 기능은 공식적으로 제공되지 않습니다.

## 설정 메뉴에서 디지털 웰빙 데이터 삭제하기

스마트폰의 설정 앱을 실행한 후 스크롤을 내려 디지털 웰빙 및 자녀 보호 기능 메뉴로 진입합니다. 우측 상단의 점 세 개 메뉴 아이콘을 누르거나 설정 세부 항목으로 들어갑니다. 데이터 관리 또는 사용 기록 삭제와 관련된 옵션이 있는지 확인합니다. 삼성 계정과 연동되어 있는 경우 클라우드에 백업된 기록까지 함께 정리해야 완전히 초기화됩니다.

## 애플리케이션 관리에서 데이터 및 캐시 삭제

더 확실하게 기록을 지우고 싶다면 설정의 애플리케이션 메뉴로 이동합니다. 목록에서 디지털 웰빙 항목을 찾아 터치한 후 저장공간 메뉴로 들어갑니다. 화면 하단에 있는 데이터 삭제 및 캐시 삭제 버튼을 순서대로 누릅니다. 이 작업을 수행하면 그동안 누적되었던 모든 앱 사용 시간 통계가 깔끔하게 초기화됩니다.

## 디지털 웰빙 기능 자체를 비활성화하는 방법

애초에 사용 시간 기록이 남지 않도록 기능을 완전히 끄는 것도 하나의 대안입니다. 디지털 웰빙 설정 화면에서 권한을 해제하거나 백그라운드 데이터 사용을 차단합니다. 서드파티 앱을 통해 이 기능을 대체하거나 제조사 설정에 따라 사용 중지 버튼을 누를 수 있습니다. 기능을 꺼두면 이후부터는 사용 시간 통계가 더 이상 수집되지 않습니다.

## 일일 앱 타이머 설정 및 변경 관리

사용 시간을 삭제하는 것뿐만 아니라 특정 앱의 과도한 사용을 막기 위해 타이머를 설정할 수 있습니다. 디지털 웰빙 메인 화면에서 앱 타이머 항목을 선택한 후 제한을 걸고 싶은 앱을 고릅니다. 하루에 허용할 시간을 직접 지정해 두면 해당 시간이 지난 후에는 앱 실행이 차단됩니다. 필요할 때 언제든지 이 타이머 설정을 해제하거나 시간을 늘릴 수 있습니다.

## 주의사항 및 소프트웨어 버전에 따른 차이

안드로이드 OS 버전이나 One UI 버전에 따라 디지털 웰빙 메뉴의 세부 구성이 다를 수 있습니다. 최신 보안 업데이트가 적용된 기기에서는 시스템 앱 데이터 삭제 방식에 제한이 있을 수 있습니다. 만약 특정 자녀 보호 기능과 연동되어 있다면 보호자 인증 번호가 필요합니다. 자세한 스마트폰 설정 방법은 삼성전자 공식 고객센터를 통해 확인하는 것이 가장 정확합니다.

갤럭시 사용 시간 기록은 애플리케이션 관리 메뉴에서 데이터 삭제를 통해 초기화할 수 있습니다. 개인 설정에 맞게 유용하게 활용하시기 바랍니다.
