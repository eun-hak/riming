컴퓨터나 스마트폰으로 유튜브를 시청하면서 다른 작업을 동시에 처리하고 싶을 때 화면 분할 기능이 유용합니다. 웹 브라우저에서 미니플레이어로 전환하거나 모바일 기기에서 팝업창 형태로 띄우는 방법을 알아두면 편리합니다. 기기별 환경에 따른 구체적인 창모드 실행 방법을 안내해 드립니다.

## PC 웹 브라우저 미니플레이어 단축키

PC에서 유튜브 영상 시청 중 키보드의 i 키를 누르면 화면이 우측 하단의 작은 미니플레이어로 축소됩니다. 이 상태에서 웹 브라우저의 다른 탭을 이동하거나 문서 작업을 계속 진행하면서 영상을 시청할 수 있습니다. 영상 재생 창 하단의 미니플레이어 아이콘을 직접 클릭해도 동일하게 전환됩니다. 원래 크기로 돌아가려면 미니플레이어 화면을 다시 클릭하거나 확장 아이콘을 누르면 됩니다.

## 브라우저 확장 프로그램을 활용한 항상 위 고정

기본 미니플레이어 외에 크롬 브라우저의 화면 속 화면 기능을 이용하면 유튜브 창을 항상 위에 띄울 수 있습니다. 영상 화면 위에서 마우스 우클릭을 두 번 연속으로 한 뒤 나타나는 메뉴에서 PIP 모드를 선택합니다. 브라우저 창 크기를 조절하거나 다른 프로그램을 전체 화면으로 띄워도 유튜브 영상이 최상단에 유지됩니다. 별도의 확장 프로그램을 설치하면 창의 투명도나 크기를 자유롭게 조절하는 부가 기능을 쓸 수 있습니다.

## 모바일 안드로이드 PiP 기능 설정 방법

안드로이드 스마트폰에서는 유튜브 앱 설정에서 화면 속 화면 기능을 활성화하여 홈 화면으로 나와도 팝업창을 유지할 수 있습니다. 스마트폰의 설정 메뉴에서 앱 권한과 특별한 접근 권한 중 다른 앱 위에 표시 권한을 유튜브에 부여해야 합니다. 영상을 보던 중 홈 버튼을 누르거나 제스처를 취하면 화면 구석에 작은 팝업창으로 영상이 재생됩니다. 팝업창의 모서리를 손가락으로 드래그하여 크기를 키우거나 줄일 수 있습니다.

## 아이폰 iOS에서의 창모드 이용 조건

아이폰에서는 유튜브 프리미엄 구독자이거나 사파리 브라우저를 데스크톱 웹 사이트 요청 모드로 우회해 이용할 수 있습니다. 사파리에서 유튜브에 접속해 전체 화면으로 재생한 뒤 홈 화면으로 나가면 자동으로 PiP 모드가 실행됩니다. 일반 무료 계정의 경우 앱 내에서는 백그라운드나 창모드가 제한되므로 브라우저 환경을 활용해야 합니다. 최신 iOS 버전과 앱 업데이트가 정상적으로 이루어져야 원활한 작동을 기대할 수 있습니다.

## 창모드 사용 중 음소거 및 재생 제어

작은 팝업창이나 미니플레이어 상태에서도 마우스나 터치로 재생, 일시정지, 건너뛰기가 가능합니다. 다른 작업에 집중하느라 소리를 잠시 꺼야 할 때는 창에 마우스를 올리고 음소거 아이콘을 누릅니다. 창의 X 버튼을 누르면 영상이 완전히 종료되므로 실수로 닫지 않도록 주의해야 합니다. 전체 화면으로 복귀하려면 팝업창 내부의 확장 버튼을 가볍게 터치합니다.

창모드를 활성화한 상태로 고사양 문서 작업이나 게임을 동시에 진행하면 기기에 부하가 걸릴 수 있습니다. 스마트폰이나 노트북의 발열이 심해지면 성능이 저하되므로 작업 강도를 조절해야 합니다. 모바일 기기에서 장시간 창모드로 영상을 켜두면 배터리 소모가 빨라지므로 충전기를 연결해 두는 것이 좋습니다.
