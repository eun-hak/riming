아이폰에서 와이파이를 연결하면 일반적으로 데이터 요금제에 포함된 셀룰러 데이터는 사용되지 않습니다. 기기는 와이파이 신호를 우선순위로 인식하여 인터넷 연결을 시도하기 때문입니다. 다만 특정 상황에서는 와이파이 연결 중에도 데이터가 미세하게 소모될 수 있어 주의가 필요합니다. 와이파이 환경에서 데이터 소모가 발생하는 원인과 이를 차단하는 설정을 상세히 안내해 드립니다.

## 와이파이 우선 연결의 기본 원리

아이폰은 와이파이와 셀룰러 데이터가 동시에 활성화된 상태에서 신호가 안정적인 와이파이를 우선적으로 선택합니다. 와이파이에 성공적으로 접속되면 데이터 통신은 모두 무선 공유기를 통해 이루어집니다. 따라서 일반적인 웹 서핑이나 영상 시청 시에는 요금제 데이터가 차감되지 않습니다. 상태 표시줄에 와이파이 아이콘이 떠 있다면 데이터 걱정 없이 인터넷을 사용할 수 있는 상태라고 판단해도 무방합니다.

## 와이파이 보조 기능의 데이터 소모

아이폰에는 와이파이 신호가 약해질 때 자동으로 셀룰러 데이터를 사용하는 와이파이 보조 기능이 있습니다. 와이파이 연결이 불안정하면 아이폰은 끊김을 방지하기 위해 데이터를 보조 수단으로 활용합니다. 이 경우 사용자는 와이파이를 쓰고 있다고 생각하지만 실제로는 데이터가 소모되고 있을 수 있습니다. 데이터 요금제가 제한적이라면 설정 메뉴의 셀룰러 항목에서 와이파이 보조 기능을 끄는 것이 안전합니다.

## 앱 업데이트 및 백그라운드 데이터

와이파이 연결이 끊긴 상태에서 앱이 백그라운드에서 데이터를 업데이트할 때 소량의 데이터가 소모될 수 있습니다. 특히 아이클라우드 동기화나 앱 자동 업데이트 설정이 켜져 있다면 와이파이 접속이 해제된 순간 데이터가 사용됩니다. 이를 방지하려면 셀룰러 데이터 설정에서 개별 앱의 데이터 사용을 제한해야 합니다. 설정 메뉴를 통해 어떤 앱이 데이터를 많이 사용하는지 확인하고 불필요한 앱은 차단하십시오.

## 와이파이 연결이 끊기는 상황 주의

기기를 잠자기 모드로 두거나 화면을 끄면 전력 절약을 위해 와이파이 연결이 일시적으로 해제될 수 있습니다. 이때 알림 메시지를 받거나 앱이 데이터를 갱신하면서 셀룰러 데이터를 사용할 가능성이 있습니다. 장시간 와이파이를 사용해야 한다면 기기 설정에서 데이터 사용을 엄격히 관리해야 합니다. 와이파이 접속을 유지하도록 설정하거나 데이터 사용 경고 설정을 활용하는 것이 도움이 됩니다.

## 셀룰러 데이터 차단 설정 방법

데이터 소모를 완전히 방지하고 싶다면 설정의 셀룰러 메뉴에서 셀룰러 데이터 자체를 끄는 방법이 가장 확실합니다. 와이파이만 사용하겠다고 결정했다면 이 기능을 끄는 것만으로도 요금제 데이터 소모를 완벽하게 막을 수 있습니다. 다만 이 상태에서는 와이파이가 없는 곳에서는 인터넷이 전혀 되지 않으므로 필요한 상황에 맞춰 기능을 켜고 꺼야 합니다. 제어 센터에서 데이터 아이콘을 눌러 빠르게 전환할 수 있습니다.

## 데이터 소모량 확인하는 법

본인의 데이터가 실제로 얼마나 소모되고 있는지 확인하려면 셀룰러 설정 메뉴를 확인하십시오. 현재까지 사용한 데이터 양과 앱별 사용량을 상세하게 보여줍니다. 와이파이 연결 중임에도 데이터가 계속 증가한다면 와이파이 보조 기능이 작동하고 있을 확률이 높습니다. 주기적으로 이 메뉴를 확인하여 데이터 관리 습관을 들이는 것이 좋습니다. 합리적인 데이터 사용을 위해 설정을 최적화하여 요금을 절약하시기 바랍니다.

와이파이 연결 시 데이터 소모는 와이파이 보조 기능 때문인 경우가 많습니다. 데이터 요금을 아끼려면 설정에서 관련 기능을 확인해 보시기 바랍니다.
