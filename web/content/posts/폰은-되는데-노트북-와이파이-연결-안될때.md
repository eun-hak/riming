스마트폰은 와이파이를 잘 잡는데 유독 노트북만 연결되지 않는다면 원인은 노트북 내부 설정에 있을 확률이 매우 높습니다. 공유기 신호는 정상적으로 송출되고 있으므로 인터넷 회선보다는 노트북의 네트워크 어댑터나 IP 설정 등을 우선적으로 점검해야 합니다. 폰이 연결된다는 것은 외부 환경은 문제가 없다는 뜻이므로, 노트북의 설정 문제를 빠르게 좁혀 해결할 수 있습니다. 노트북 와이파이 연결 오류를 해결하기 위한 체크리스트를 정리합니다.

## 노트북 네트워크 어댑터 설정 확인

스마트폰은 잘 되는데 노트북만 안 된다면 노트북의 무선 랜카드가 일시적인 오류를 일으켰을 가능성이 큽니다. 제어판의 장치 관리자로 들어가 네트워크 어댑터 항목을 확인합니다. 무선 랜카드 장치에 노란색 느낌표가 떠 있다면 드라이버 충돌이 발생한 상태입니다. 해당 장치를 제거한 후 노트북을 다시 시작하면 시스템이 자동으로 드라이버를 다시 잡습니다. 드라이버를 삭제하고 재설치하는 것만으로도 대부분의 연결 문제가 해결됩니다.

## IP 주소 충돌 및 자동 할당 확인

노트북이 다른 기기와 동일한 IP를 사용하려고 하면 연결이 거부될 수 있습니다. 네트워크 및 인터넷 설정의 어댑터 옵션 변경 메뉴로 들어갑니다. Wi-Fi 속성을 선택하고 인터넷 프로토콜 버전 4 설정을 확인합니다. IP 주소와 DNS 서버 주소가 자동으로 받기로 되어 있는지 체크하십시오. 고정 IP가 설정되어 있다면 공유기에서 할당하는 IP와 충돌이 발생할 수 있습니다. 자동으로 받기로 변경한 뒤 노트북을 재부팅하여 연결을 다시 시도합니다.

## 와이파이 프로필 삭제 후 재연결

이전에 저장해둔 와이파이 정보가 꼬여서 연결이 안 되는 경우도 많습니다. 설정의 네트워크 및 인터넷 메뉴에서 알려진 네트워크 관리 항목으로 이동합니다. 연결하려는 와이파이 이름을 찾아 네트워크 삭제 버튼을 누릅니다. 저장된 정보를 완전히 지운 뒤 와이파이 목록에서 다시 해당 네트워크를 선택합니다. 비밀번호를 처음부터 다시 입력하면 새로운 인증 과정을 거치면서 연결 오류가 해소될 수 있습니다.

## 윈도우 네트워크 초기화 기능 활용

복잡한 설정 변경이 어렵다면 윈도우의 네트워크 초기화 기능을 사용합니다. 설정 메뉴에서 고급 네트워크 설정으로 이동하여 네트워크 초기화를 진행합니다. 이 기능은 모든 네트워크 어댑터를 제거하고 다시 설치하며, 네트워크 관련 설정을 공장 초기화 상태로 돌립니다. 작업이 완료되면 자동으로 컴퓨터가 재부팅됩니다. 이 과정에서 저장된 와이파이 비밀번호가 모두 삭제되므로 다시 입력해야 하지만 가장 확실한 해결 방법 중 하나입니다.

## 보안 프로그램 및 방화벽 차단 점검

노트북에 설치된 방화벽이나 백신 프로그램이 와이파이 연결을 보안 위협으로 간주하여 차단할 수 있습니다. 특히 공공 와이파이나 보안이 강화된 환경에서는 이런 경우가 자주 발생합니다. 방화벽 설정을 일시적으로 끄고 연결이 되는지 확인해 보십시오. 만약 연결이 성공한다면 방화벽 설정에서 해당 네트워크를 신뢰할 수 있는 네트워크로 추가해야 합니다. 보안 프로그램이 네트워크 어댑터의 작동을 방해하고 있는지 확인하는 것도 필요합니다.

## 공유기 설정 페이지에서 기기 차단 확인

드물게 공유기 설정에서 특정 기기의 MAC 주소를 차단해 두었을 수도 있습니다. 공유기 관리자 페이지에 접속하여 차단된 기기 목록이 있는지 확인합니다. 스마트폰은 연결되어 있지만 노트북의 MAC 주소가 차단 목록에 있다면 연결이 불가능합니다. 공유기 설정을 초기화하거나 차단 목록에서 노트북의 MAC 주소를 삭제하면 즉시 연결이 가능해집니다. 가족 중 누군가 실수로 기기를 차단했는지 확인해 보는 것도 좋은 방법입니다.

노트북만 연결이 안 된다면 노트북의 IP 설정과 드라이버를 먼저 점검하십시오. 위 방법들을 따라 하면 대부분의 연결 문제를 해결할 수 있습니다.
