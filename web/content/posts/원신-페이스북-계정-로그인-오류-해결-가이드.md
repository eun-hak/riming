원신을 플레이하며 페이스북 계정이 2개 이상일 경우, 원하는 계정으로 로그인이 되지 않는 현상은 브라우저의 자동 로그인 정보 때문입니다. 기기에 저장된 페이스북 쿠키가 이전에 로그인했던 계정을 기억하고 있어 발생하는 문제입니다. 이 문제를 해결하기 위해서는 브라우저의 캐시를 삭제하거나 로그아웃 과정을 거쳐야 합니다. 올바른 계정으로 접속하는 방법을 알아봅니다.

## 페이스북 앱 및 웹 브라우저 로그아웃

원신 게임 내 로그인 화면에서 페이스북을 선택하기 전에 페이스북 앱과 모바일 브라우저를 먼저 확인하십시오. 페이스북 앱에서 현재 로그인된 계정을 로그아웃해야 합니다. 또한 사파리나 크롬 등 기본 브라우저에서도 페이스북 사이트에 접속하여 로그아웃하십시오. 모든 브라우저에서 로그아웃해야 원신에서 새로운 계정을 입력할 수 있는 창이 뜹니다. 이 단계를 생략하면 계속 이전 계정으로 자동 로그인됩니다.

## 브라우저 캐시 및 쿠키 삭제

브라우저에 남은 로그인 기록을 완전히 지우려면 캐시와 쿠키를 삭제해야 합니다. 설정 메뉴에서 인터넷 사용 기록 삭제를 선택하고 쿠키 데이터를 지워주십시오. 이 작업을 수행하면 모든 사이트에서 로그아웃되지만 계정 오류는 확실히 해결됩니다. 캐시 삭제 후 원신을 다시 실행하면 페이스북 로그인 창이 새로 뜹니다. 이때 원하는 계정의 아이디와 비밀번호를 직접 입력할 수 있습니다.

## 시크릿 모드 활용하여 로그인하기

브라우저의 시크릿 모드나 개인 정보 보호 모드를 활용하는 것도 방법입니다. 시크릿 모드는 로그인 정보를 저장하지 않기 때문에 매번 새로운 로그인을 할 수 있습니다. 원신 로그인 화면에서 브라우저가 열릴 때 시크릿 모드를 선택하십시오. 혹은 브라우저 앱에서 미리 시크릿 모드를 켜고 페이스북에 접속해 보십시오. 그러면 기존 계정 정보에 영향을 받지 않고 원하는 계정으로 접속이 가능합니다.

## 원신 게임 데이터 캐시 정리

게임 자체의 데이터가 꼬여있다면 설정 메뉴에서 게임 캐시를 정리해 보십시오. 로그인 오류는 브라우저 문제인 경우가 많지만 게임 내 설정이 잘못되어 있을 수도 있습니다. 원신 타이틀 화면의 수리 도구를 사용하여 게임 파일을 점검하는 것도 도움이 됩니다. 파일 점검은 누락된 파일을 복구하고 설정을 초기화합니다. 이 과정 후 다시 로그인을 시도해 보십시오.

## 다른 기기에서의 로그인 테스트

본인의 기기 문제인지 확인하기 위해 다른 스마트폰에서 로그인을 시도해 보십시오. 다른 기기에서 원하는 계정으로 로그인이 잘 된다면 현재 기기의 브라우저 설정이 확실한 원인입니다. 다른 기기에서 성공했다면 해당 기기의 브라우저 설정을 동일하게 적용하십시오. PC 버전 원신을 사용한다면 PC 브라우저의 쿠키를 삭제하는 것이 훨씬 빠릅니다. 환경을 바꿔보는 것이 원인 파악에 좋습니다.

## 미호요 통합 계정으로 전환 고려

페이스북 계정은 외부 연동 방식이라 오류가 잦을 수 있습니다. 원신 공식 홈페이지에서 미호요 통합 계정을 생성하여 페이스북 계정을 연동해 두는 것을 권장합니다. 통합 계정을 사용하면 외부 브라우저의 로그인 상태에 영향을 받지 않고 접속할 수 있습니다. 보안 측면에서도 훨씬 안전합니다. 번거롭더라도 계정 연동을 완료해두면 앞으로 로그인 오류로 고생하지 않아도 됩니다.

원신 페이스북 로그인 오류는 브라우저에 남은 이전 계정 정보 때문입니다. 모든 브라우저에서 로그아웃하고 캐시를 삭제하거나 통합 계정을 연동하여 해결하시기 바랍니다.
