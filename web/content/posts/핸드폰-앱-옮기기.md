핸드폰을 교체할 때 기존에 사용하던 앱과 데이터를 어떻게 옮길지 고민하시는군요. 최근에는 제조사에서 제공하는 데이터 이동 서비스를 이용하면 앱 구성과 데이터를 거의 그대로 복구할 수 있습니다. 기기 변경 시 활용할 수 있는 가장 효율적인 방법을 정리해 드립니다.

## 제조사별 데이터 이동 서비스 활용

삼성 갤럭시를 사용한다면 스마트 스위치(Smart Switch) 앱을 활용하는 것이 가장 간편합니다. 아이폰으로 이동할 때는 애플의 'iOS로 이동' 앱을 사용하면 됩니다. 이 서비스들은 앱 목록뿐만 아니라 사진, 연락처, 메시지까지 한 번에 옮겨줍니다. 두 기기를 나란히 두고 무선 연결을 하면 자동으로 데이터가 전송됩니다. 과정이 매우 직관적이라 초보자도 쉽게 따라 할 수 있습니다.

## 앱 내 계정 로그인 방식 확인

앱 자체는 이동해도 내부 데이터는 서버에 저장되는 경우가 많습니다. 카카오톡이나 게임 앱 등은 해당 앱 내에서 별도의 백업 과정을 거쳐야 합니다. 특히 카카오톡은 설정 메뉴의 대화 백업 기능을 반드시 활용하십시오. 구글이나 페이스북 계정으로 연동된 앱은 새 기기에서 로그인만 하면 데이터가 불러와집니다. 앱별로 데이터 동기화 방식이 다르니 미리 확인이 필요합니다.

## 공인인증서 및 금융 앱 이전

금융 앱은 보안상 이유로 데이터를 직접 옮길 수 없는 경우가 많습니다. 새 기기에서 각 은행 앱을 새로 설치하고 인증 절차를 다시 밟아야 합니다. 공동인증서 또한 PC나 클라우드를 통해 새 기기로 복사해 넣어야 합니다. 금융 거래가 많다면 기기 변경 전 미리 인증서 내보내기 기능을 확인해 두십시오. 번거롭더라도 보안을 위해 필수적으로 수행해야 하는 과정입니다.

## 클라우드 서비스 활용한 데이터 보관

구글 드라이브나 아이클라우드와 같은 클라우드 서비스를 적극 활용하십시오. 평소에 자동 백업 설정을 해두면 기기를 바꿔도 데이터를 즉시 복구할 수 있습니다. 사진이나 문서 파일은 물론 앱 설정까지 클라우드에 저장되는 경우가 많습니다. 기기 변경 전 모든 데이터가 최신 상태로 백업되었는지 클라우드 확인창을 열어보십시오. 클라우드만 잘 활용해도 데이터 유실 걱정을 덜 수 있습니다.

## 앱 설치 및 재인증 과정

데이터 이동 서비스를 이용해도 일부 앱은 다시 설치가 필요할 수 있습니다. 데이터만 옮겨지고 앱 실행 파일은 다시 다운로드해야 하는 방식이 많기 때문입니다. 새 기기에서 앱스토어나 플레이스토어에 접속하여 필요한 앱을 일괄 설치하십시오. 설치 후에는 기존 아이디와 비밀번호로 로그인하여 정상 작동 여부를 확인해야 합니다. 보안 정책이 강화된 앱은 기기 변경 시 본인 인증이 추가로 요구됩니다.

## 데이터 이전 후 최종 점검

모든 이전이 완료되었다면 기존 기기를 초기화하기 전에 데이터를 확인하십시오. 중요한 사진이나 문서가 누락되지 않았는지 꼼꼼히 살피는 과정이 필요합니다. 특히 메신저 대화 내용이나 금융 앱 실행 여부를 반드시 체크하십시오. 이상이 없음을 확인한 뒤에야 기존 기기를 초기화하거나 처분하는 것이 안전합니다. 데이터가 완전히 옮겨졌다는 확신이 들 때까지 기존 기기는 보관하십시오.

제조사에서 제공하는 데이터 이동 앱을 사용하면 대부분의 데이터를 쉽게 옮길 수 있습니다. 금융 앱과 메신저 등은 개별 인증과 백업이 필요하므로 미리 점검하십시오. 모든 데이터 확인 전까지는 기존 기기를 초기화하지 마시길 바랍니다.
