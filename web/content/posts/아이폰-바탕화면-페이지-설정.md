아이폰 바탕화면의 페이지 순서를 바꾸거나 불필요한 홈 화면 페이지를 숨기는 방법을 알아봅니다. 결론부터 말씀드리면 홈 화면 빈 곳을 길게 터치하여 편집 모드로 진입한 뒤 하단의 페이지 점 아이콘을 누르면 쉽게 관리할 수 있습니다. 앱 아이콘을 원하는 위치로 드래그하여 페이지 간 이동을 자유롭게 할 수 있습니다. 최신 iOS 버전에 따라 인터페이스가 일부 다를 수 있으니 참고하시기 바랍니다.

## 홈 화면 페이지 순서 변경하기

바탕화면의 빈 공간을 손가락으로 길게 누르면 앱 아이콘들이 흔들리며 편집 모드가 활성화됩니다. 화면 하단에 위치한 페이지를 나타내는 작은 점 모양의 인디케이터를 터치합니다. 축소된 전체 페이지 미리보기 화면이 나타나면 원하는 페이지를 길게 눌러 좌우로 이동합니다. 자리를 잡은 뒤 우측 상단의 완료 버튼을 누르면 순서 변경이 저장됩니다.

## 특정 홈 화면 페이지 숨기기 기능

자주 쓰지 않는 앱이 모여 있는 페이지를 완전히 삭제하지 않고 임시로 숨길 수 있습니다. 편집 모드에서 하단 점 아이콘을 눌러 전체 페이지 보기로 진입합니다. 숨기고 싶은 페이지 아래에 있는 체크 표시를 해제하면 홈 화면에서 즉시 사라집니다. 나중에 다시 보고 싶을 때는 같은 경로로 들어가 체크박스를 다시 활성화하면 됩니다.

## 앱 아이콘을 다른 페이지로 이동하기

특정 앱을 다른 페이지나 새로운 페이지로 옮기려면 아이콘을 길게 눌러 흔들림 상태로 만듭니다. 앱을 손가락으로 누른 채 화면의 맨 왼쪽이나 오른쪽 끝으로 드래그합니다. 잠시 멈추면 해당 방향의 다음 페이지로 앱이 스르륵 넘어갑니다. 원하는 위치에 손가락을 떼어 아이콘을 안정적으로 안착시킵니다.

## 새로운 홈 화면 페이지 추가하는 법

모든 페이지가 가득 차서 새로운 페이지를 만들고 싶을 때는 앱을 가장 오른쪽 페이지 끝으로 끌고 갑니다. 화면 경계선에서 잠시 대기하면 새로운 빈 페이지가 자동으로 생성됩니다. 생성된 페이지에 앱을 떨어뜨리면 해당 페이지가 활성화됩니다. 불필요해진 빈 페이지는 앱을 모두 비우면 자연스럽게 사라집니다.

## 앱 보관함을 활용한 바탕화면 정리

바탕화면 페이지를 늘리는 대신 홈 화면에서 아예 앱을 제거하고 앱 보관함에 보관할 수 있습니다. 앱을 길게 눌러 홈 화면에서 제거를 누른 후 앱 보관함으로 이동을 선택합니다. 자주 쓰지 않는 앱들은 바탕화면에서 숨기고 검색이나 보관함에서 찾아 쓸 수 있습니다. 이 기능을 활용하면 첫 번째 페이지를 매우 깔끔하게 유지할 수 있습니다.

## 집중 모드와 연동된 페이지 설정

업무 시간이나 수면 시간에 따라 특정 홈 화면 페이지만 보이도록 집중 모드와 연동할 수 있습니다. 설정의 집중 모드 메뉴로 들어가 특정 모드 활성화 시 보여질 홈 화면을 커스텀합니다. 불필요한 알림을 주는 앱이 담긴 페이지를 숨겨 업무 집중도를 높일 수 있습니다. 시간대별로 최적화된 아이폰 화면 환경을 구축합니다.

아이폰 바탕화면 페이지는 편집 모드와 점 아이콘을 통해 숨기기와 정리가 가능합니다. 깔끔하게 홈 화면을 세팅하여 편리하게 사용하시기 바랍니다.
