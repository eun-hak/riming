아이폰에서 프로젝트 세카이(프세카)를 플레이하다가 화면이 사라지거나 데이터가 날아가는 현상은 주로 앱 오류나 캐시 충돌 때문입니다. 우선 앱을 강제로 종료하고 재실행하는 것만으로도 해결되는 경우가 많습니다. 만약 데이터 자체가 사라졌다면 계정 연동 상태를 확인해야 합니다. 당황스러운 상황을 해결하기 위한 단계별 조치 방법을 정리합니다.

## 앱 강제 종료 및 재실행

화면이 멈추거나 표시되지 않을 때는 앱을 강제로 종료하십시오. 아이폰 하단에서 위로 스와이프하여 앱 전환기를 열고 프세카를 위로 밀어 종료합니다. 이후 다시 앱을 실행하여 정상적으로 화면이 뜨는지 확인하십시오. 일시적인 메모리 부족 현상일 경우 이 방법으로 대부분 해결됩니다. 재실행 후에도 문제가 지속되면 기기를 재부팅하십시오.

## 앱 데이터 캐시 지우기

설정 메뉴 내에서 데이터 복구 기능을 활용할 수 있습니다. 타이틀 화면 우측 상단의 메뉴 버튼을 눌러 데이터 복구 항목을 선택하십시오. 이 기능은 다운로드된 게임 데이터를 다시 확인하고 손상된 파일을 수정합니다. 데이터가 완전히 삭제되는 것이 아니므로 안심하고 진행해도 됩니다. 네트워크 환경이 안정적인 상태에서 시도하는 것이 좋습니다.

## 계정 연동 상태 확인

화면이 날아간 것이 아니라 계정이 로그아웃된 것일 수 있습니다. 게임 내 옵션이나 타이틀 화면에서 데이터 인계 설정을 확인하십시오. Game Center나 구글 계정, 혹은 별도로 설정한 인계 코드가 있는지 찾아야 합니다. 계정 연동이 되어 있다면 앱을 삭제 후 재설치해도 데이터를 복구할 수 있습니다. 연동 정보를 잊었다면 고객센터에 문의해야 합니다.

## 앱 삭제 후 재설치 시 주의사항

앱 재설치는 최후의 수단으로 사용해야 합니다. 삭제 전 반드시 계정 연동이 확실한지 다시 한번 체크하십시오. 연동되지 않은 상태에서 앱을 삭제하면 게임 데이터가 영구적으로 손실됩니다. 재설치 시에는 와이파이 환경에서 진행하여 데이터 소모를 방지하십시오. 설치 완료 후 초기 화면에서 데이터 인계 버튼을 눌러 연동 계정으로 로그인합니다.

## 아이폰 소프트웨어 및 앱 업데이트

iOS 버전이 너무 낮거나 앱 버전이 구버전일 때 오류가 발생할 수 있습니다. 앱스토어에서 프세카가 최신 버전인지 확인하고 업데이트하십시오. 아이폰 설정에서 운영체제 업데이트가 있는지 체크하는 것도 중요합니다. 최신 버전에서 수정된 오류가 많으므로 항상 최신 상태를 유지하십시오. 업데이트 후에도 문제가 반복되면 기기 호환성을 의심해 봐야 합니다.

## 공식 고객센터 문의 방법

위의 방법으로도 해결되지 않는다면 공식 고객센터에 문의하십시오. 게임 내 문의 폼을 이용하거나 공식 홈페이지의 지원 메일을 활용합니다. 이때 본인의 유저 ID와 사용 기기 정보를 상세히 기재해야 합니다. 결제 내역이 있다면 이를 증빙 자료로 첨부하여 복구를 요청하십시오. 고객센터의 답변은 시간이 다소 소요될 수 있으니 기다림이 필요합니다.

프세카 화면 오류는 대부분 캐시 복구로 해결할 수 있습니다. 계정 연동이 되어 있다면 재설치로도 충분히 복구가 가능합니다. 연동 정보를 미리 확보하여 데이터 손실을 방지하시기 바랍니다.
