와이파이 공유기에서 인터넷 연결 없음 메시지가 뜨는 상황은 외부 신호 문제이거나 공유기 내부 설정 오류일 가능성이 큽니다. 무선 신호는 잡히는데 실제 데이터 통신이 안 되는 것은 공유기가 인터넷 회선과 제대로 소통하지 못하고 있다는 뜻입니다. 이를 해결하기 위해 공유기 상태를 점검하고 네트워크를 재설정하는 방법을 정리했습니다. 아래의 조치들을 순서대로 따라 하면 대부분의 연결 문제를 즉시 해결할 수 있습니다.

## 인터넷 모뎀 및 공유기 확인

가장 먼저 통신사에서 제공한 모뎀의 상태를 확인하십시오. 모뎀의 LED 표시등이 정상적으로 켜져 있는지, 혹시 빨간색 불이 들어와 있지는 않은지 살펴봅니다. 빨간색 불은 외부 회선 장애를 의미하므로 이 경우 사용자가 해결할 수 없으며 통신사 고객센터에 연락해야 합니다. 모뎀과 공유기를 연결하는 랜선이 헐겁지 않은지도 확인하십시오. 두 기기의 전원을 모두 끄고 1분 뒤에 모뎀부터 순서대로 켜는 방식이 가장 효과적입니다.

## 공유기 관리자 페이지 접속 점검

공유기의 관리자 페이지에 접속하여 인터넷 연결 상태를 확인해 보십시오. 보통 웹 브라우저 주소창에 공유기 제조사가 지정한 IP 주소를 입력하면 접속할 수 있습니다. 관리자 화면에서 '인터넷 연결됨' 혹은 '연결 없음' 상태를 바로 확인할 수 있습니다. 만약 연결 없음으로 나온다면 공유기 내부 설정을 다시 잡아야 합니다. 관리자 페이지 내의 '마법사' 기능을 사용하면 자동으로 설정을 다시 구성해주어 편리합니다.

## 무선 채널 설정 및 간섭 확인

주변에 와이파이 공유기가 많으면 신호 간섭으로 인해 인터넷이 끊길 수 있습니다. 관리자 페이지에서 무선 채널 설정을 '자동'에서 다른 채널로 변경해 보십시오. 2.4GHz 대역보다는 5GHz 대역을 사용하는 것이 신호 간섭을 피하고 훨씬 빠른 속도를 내는 방법입니다. 채널 변경만으로도 연결이 끊기는 현상이 눈에 띄게 줄어들 수 있습니다. 특히 아파트나 오피스텔처럼 와이파이가 밀집한 지역에서는 필수적인 조치입니다.

## IP 주소 충돌 해결 방법

여러 기기가 동시에 접속하면서 IP 주소가 충돌하여 인터넷이 안 될 수 있습니다. 공유기를 재부팅하면 새로운 IP를 다시 할당받게 되어 대부분 해결됩니다. 만약 특정 기기에서만 문제가 발생한다면 해당 기기의 네트워크 설정을 'IP 자동 할당(DHCP)'으로 변경하십시오. 정적인 IP를 수동으로 입력해 두었다면 오류의 원인이 될 수 있습니다. 공유기 설정에서 DHCP 서버 기능이 정상적으로 활성화되어 있는지 확인하는 것도 중요합니다.

## 공유기 펌웨어 업그레이드

오래된 펌웨어는 최신 통신 규격과 충돌하여 연결 오류를 일으키는 주범입니다. 제조사 홈페이지를 통해 자신의 모델에 맞는 최신 펌웨어를 다운로드하여 업데이트하십시오. 최근의 공유기들은 관리자 페이지에서 버튼 하나로 온라인 업데이트를 지원합니다. 펌웨어 개선 사항에는 보안 패치뿐만 아니라 인터넷 연결 안정성 강화가 포함됩니다. 정기적인 업데이트는 공유기의 수명을 늘리고 성능을 최상으로 유지하는 비결입니다.

## 공유기 교체 및 고장 판별

위의 모든 조치를 취해도 해결되지 않는다면 공유기 자체의 하드웨어 고장일 수 있습니다. 공유기도 전자기기이므로 수명이 있으며, 오랜 시간 사용하면 내부 회로가 손상될 수 있습니다. 특히 여름철 열기로 인해 내부 부품이 고장 나는 경우가 많습니다. 다른 공유기를 빌려 연결해 보거나, 통신사에서 임대해 준 공유기를 사용 중이라면 기기 교체를 요청하십시오. 하드웨어 고장은 소프트웨어 설정으로는 결코 고칠 수 없습니다.

인터넷 연결 없음은 모뎀과 공유기 재부팅으로 해결되는 경우가 많습니다. 지속적인 문제라면 통신사 회선 상태를 확인하고, 공유기 펌웨어를 최신으로 업데이트해 보시기 바랍니다.
