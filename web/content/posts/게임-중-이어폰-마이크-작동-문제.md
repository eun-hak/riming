게임을 할 때 이어폰을 연결했음에도 마이크가 작동하지 않는다면 대부분 PC나 콘솔의 오디오 입력 설정이 잘못되어 있기 때문입니다. 소리는 이어폰으로 나오지만 마이크는 여전히 컴퓨터 내장 마이크를 사용하고 있을 확률이 높습니다. 하드웨어 연결 방식과 소프트웨어 설정이 일치하지 않을 때 발생하는 문제들을 해결할 수 있는 방법을 구체적으로 정리해 드립니다.

## 입력 장치 설정 확인

PC의 사운드 설정에서 마이크 입력 장치가 올바르게 선택되었는지 확인하십시오. 윈도우 설정의 소리 메뉴로 들어가 입력 장치 항목을 봅니다. 여기서 현재 연결된 이어폰 마이크가 목록에 있는지 체크하고, 마이크 테스트 바가 움직이는지 확인하십시오. 다른 장치가 기본값으로 되어 있다면 이어폰 마이크로 수동 변경해야 합니다. 이 설정만 바꿔도 해결되는 경우가 많습니다.

## 게임 내부 오디오 설정 변경

윈도우 설정이 정상인데도 게임에서만 마이크가 안 된다면 게임 내부 설정을 확인해야 합니다. 게임의 오디오 또는 보이스 채팅 설정으로 들어가 입력 장치를 해당 이어폰 마이크로 지정하십시오. 게임은 윈도우 설정과 별개로 자체적인 입력 장치를 요구하는 경우가 많습니다. 여기서 마이크 감도를 조절하거나 테스트 버튼을 눌러 소리가 들어오는지 확인하십시오.

## 단자 연결 상태 및 어댑터 확인

이어폰의 단자가 3극인지 4극인지 확인하십시오. 일반적인 3극 단자는 마이크 기능이 포함되어 있지 않습니다. 마이크가 달린 이어폰은 4극 단자여야 합니다. PC 본체에 꽂을 때 마이크와 오디오 단자가 분리되어 있다면 Y자형 젠더를 사용해야 마이크를 사용할 수 있습니다. 단자가 헐겁게 꽂혀 있으면 접촉 불량으로 마이크가 인식되지 않습니다.

## 마이크 권한 및 보안 설정

윈도우 보안 설정에서 특정 앱의 마이크 접근 권한이 차단되어 있을 수 있습니다. 개인 정보 및 보안 메뉴의 마이크 탭으로 이동하여 게임 앱이 마이크를 사용할 수 있도록 허용되어 있는지 확인하십시오. 권한이 거부되어 있으면 아무리 설정을 바꿔도 마이크가 작동하지 않습니다. 앱별 권한 허용을 반드시 켜두어야 합니다.

## 드라이버 업데이트 및 재설치

오디오 드라이버가 구버전이거나 오류가 있다면 마이크 인식이 안 될 수 있습니다. 장치 관리자를 열어 오디오 입력 및 출력 항목을 확인하십시오. 마이크 드라이버를 우클릭하여 업데이트하거나 장치를 제거한 뒤 재부팅하여 자동으로 재설치되도록 하십시오. 드라이버가 새로 잡히면 대부분의 오디오 관련 문제는 해결됩니다. 메인보드 홈페이지에서 최신 드라이버를 받는 것이 좋습니다.

## 이어폰 고장 여부 테스트

위의 모든 설정을 확인해도 안 된다면 이어폰 자체의 마이크 고장 가능성을 의심해야 합니다. 이어폰을 다른 기기(스마트폰 등)에 연결하여 마이크가 정상적으로 녹음되는지 테스트하십시오. 다른 기기에서도 마이크가 안 된다면 이어폰의 마이크 단선일 가능성이 매우 높습니다. 이럴 때는 이어폰을 수리하거나 교체해야 합니다. 고장 여부를 먼저 판별하는 것이 중요합니다.

게임 중 마이크 문제는 대부분 윈도우나 게임 내 입력 장치 설정 오류입니다. 설정 메뉴에서 입력 장치를 정확히 선택하고, 이어폰의 단자 규격을 확인하여 연결해 보시기 바랍니다.
