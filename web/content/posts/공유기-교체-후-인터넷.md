가정에서 인터넷 공유기를 새로 바꾼 직후에 데스크탑이나 노트북에서 와이파이가 연결되지 않는 문제가 자주 발생합니다. 기존 공유기와 새 기기의 네트워크 이름이나 보안 설정이 달라지면서 기기들이 올바른 신호를 잡지 못하기 때문입니다. 대부분의 연결 오류는 간단한 네트워크 재검색이나 IP 설정 초기화 과정을 통해 정상화할 수 있습니다.

## 새로운 와이파이 이름과 비밀번호 확인

공유기를 교체하면 기본적으로 제조사에서 설정한 새로운 무선 네트워크 이름과 비밀번호가 부여됩니다. 컴퓨터의 와이파이 목록을 열어 예전 이름이 아닌 새로 바뀐 공유기의 SSID를 선택하고 접속해야 합니다. 새 공유기 하단이나 측면에 부착된 기기 라벨을 통해 정확한 초기 비밀번호를 확인할 수 있습니다. 간혹 비밀번호의 영문 대소문자를 혼동하여 인증 실패가 뜨는 경우가 많으므로 주의 깊게 입력해야 합니다. 올바른 네트워크를 선택하는 것만으로도 대부분의 접속 불가 문제는 곧바로 해결됩니다.

## 네트워크 어댑터 및 무선 랜카드 재부팅

컴퓨터의 무선 랜카드가 이전 공유기의 연결 정보를 기억하고 있어 새로운 신호를 정상적으로 인식하지 못할 수 있습니다. 이럴 때는 컴퓨터의 제어판이나 네트워크 설정에서 무선 랜카드를 사용 안 함으로 바꾼 뒤 다시 사용 함으로 켭니다. 윈도우 작업표시줄의 와이파이 아이콘을 우클릭하여 문제 해결 도구를 실행하는 것도 유용한 방법입니다. 시스템이 스스로 네트워크 오류를 진단하고 드라이버를 재시작하여 새로운 IP를 받아오도록 유도합니다. 하드웨어 수준의 가벼운 재부팅은 통신 장비 교체 시 필수적인 점검 과정입니다.

## 이전 네트워크 프로필 기억 삭제하기

컴퓨터 운영체제는 이전에 접속했던 와이파이의 보안 키와 IP 설정 값을 안전하게 저장하는 프로필 기능을 가지고 있습니다. 이름은 같지만 내부 MAC 주소가 바뀐 새 공유기와 충돌을 일으키므로 기존 프로필을 완전히 삭제해야 합니다. 네트워크 및 인터넷 설정의 알려진 네트워크 관리 메뉴로 들어가 예전 공유기 이름의 네트워크를 삭제합니다. 그 후 깨끗해진 상태에서 새 공유기를 다시 검색하여 비밀번호를 넣고 새로 연결을 시도합니다. 찌꺼기 데이터가 말끔히 정리되어야 원활한 인터넷 통신이 이루어집니다.

## 인터넷 랜선 물리적 연결 상태 점검

무선 와이파이뿐만 아니라 공유기 자체에 메인 인터넷 랜선이 올바른 포트에 꽂혀 있는지 물리적으로 확인해야 합니다. 통신사 모뎀에서 나온 선은 공유기의 WAN 포트에 꽂혀야 하며 컴퓨터로 가는 유선 선은 LAN 포트에 연결됩니다. 공유기를 교체하는 과정에서 선이 느슨하게 체결되었거나 포트 위치가 바뀌어 인터넷 신호 자체가 들어오지 않을 수 있습니다. 모든 랜선을 뽑았다가 딸깍 소리가 나도록 단단히 다시 꽂아 신호 흐름을 정상화합니다. 하드웨어 연결 불량은 소프트웨어 설정으로 절대 해결할 수 없는 대표적인 원인입니다.

## 컴퓨터 네트워크 IP 주소 및 DNS 갱신

공유기가 바뀌면서 내부 네트워크 대역대가 달라져 기존 컴퓨터가 가지고 있던 IP 주소를 더 이상 사용할 수 없게 됩니다. 이 문제를 해결하기 위해 명령 프롬프트를 열어 IP 주소를 강제로 갱신해 주는 작업이 필요합니다. 검은색 창에 명령어를 입력하여 기존 IP 임대 정보를 반환하고 새 공유기로부터 새로운 주소를 받아옵니다. 이 과정은 엉켜 있던 내부 통신 경로를 정리하고 인터넷 신호가 컴퓨터까지 원활하게 도달하도록 돕습니다. 네트워크 명령어 사용이 어렵다면 컴퓨터를 완전히 껐다가 다시 켜는 것으로 대체할 수 있습니다.

## 공유기 설정 페이지 접속 및 펌웨어 확인

새로 구매한 공유기의 초기 설정에 문제가 있거나 펌웨어가 구버전이어서 특정 컴퓨터와 호환성 충돌이 생길 수 있습니다. 스마트폰이나 컴퓨터를 유선으로 연결한 뒤 공유기 관리자 주소에 접속하여 기본 설정을 점검합니다. 무선 채널 설정이 비정상적이거나 MAC 주소 필터링 기능이 실수로 켜져 있는지 확인해야 합니다. 필요하다면 공유기 설정을 공장 초기화 상태로 되돌리고 처음부터 다시 설정하는 것이 안전합니다. 정확한 관리자 접속 방법은 사용 중인 공유기 모델별 공식 채널에서 최신 기준 확인이 필요합니다.

공유기 교체 후 인터넷 안 됨 현상은 새 이름 연결과 이전 프로필 삭제로 대처할 수 있습니다. 물리적 랜선 연결과 IP 갱신 과정을 거쳐 무선 네트워크를 정상적으로 이용하시기 바랍니다.
