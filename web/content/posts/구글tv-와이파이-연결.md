구글TV 홈 화면에서 우측 상단에 위치한 프로필 아이콘이나 톱니바퀴 모양의 설정 아이콘을 선택하여 메뉴로 진입해야 합니다. 리모컨의 설정 버튼을 바로 누르는 방법도 기종에 따라 지원되니 확인이 필요합니다. 설정 메뉴에 들어가면 여러 항목 중 네트워크 및 인터넷 옵션을 찾아 선택합니다. 해당 메뉴가 활성화되어 있는지 확인하고 하위 항목으로 이동하여 현재 상태를 체크합니다. 여기서 와이파이 스위치를 켬 상태로 변경해야 주변의 신호를 검색할 수 있습니다. 만약 설정 메뉴가 보이지 않는다면 홈 화면의 상단 탭을 다시 한번 살펴보시기 바랍니다. 복잡한 과정 없이 리모컨 조작만으로 모든 설정이 가능하므로 차근차근 따라 해 보시길 권장합니다.

## 사용 가능한 무선 네트워크 선택하기

네트워크 메뉴에 진입하면 현재 구글TV 주변에서 감지되는 와이파이 목록이 화면에 나타납니다. 자신이 사용하는 공유기의 SSID 즉 이름이 정확히 일치하는지 확인한 뒤 해당 항목을 리모컨으로 선택합니다. 목록에 원하는 네트워크가 보이지 않는다면 스캔 버튼을 눌러 다시 검색을 시도해야 합니다. 공유기가 2.4GHz와 5GHz 대역을 모두 지원한다면 가급적 속도가 빠른 5GHz 대역을 선택하는 것이 영상 시청에 유리합니다. 단 신호 강도가 약할 경우 연결이 불안정할 수 있으니 신호 막대 개수를 확인하는 것이 중요합니다. 목록에서 네트워크를 선택하면 비밀번호 입력 창이 나타나며 다음 단계로 넘어갈 준비를 마칩니다.

## 와이파이 비밀번호 정확하게 입력하기

네트워크를 선택한 후에는 화면에 나타나는 가상 키보드를 사용하여 와이파이 비밀번호를 입력해야 합니다. 대소문자와 특수문자가 포함되어 있다면 리모컨의 방향키를 사용하여 정확하게 입력하는 것이 핵심입니다. 비밀번호가 틀리면 연결 실패 메시지가 뜨므로 입력 내용을 한 번 더 확인하는 과정이 필요합니다. 리모컨의 입력 방식이 불편하다면 구글 홈 앱을 연동하여 스마트폰 키보드를 활용하는 방법도 있습니다. 비밀번호 입력이 완료되면 확인 또는 연결 버튼을 눌러 서버와의 통신을 시작합니다. 연결 성공이라는 문구가 나타날 때까지 잠시 대기하며 네트워크 설정을 마무리합니다.

연결이 완료된 후에는 실제로 인터넷 사용이 가능한지 테스트를 진행하는 것이 좋습니다. 구글TV 내의 유튜브나 넷플릭스 앱을 실행하여 영상이 원활하게 재생되는지 확인해 봅니다. 만약 앱이 정상적으로 작동하지 않는다면 네트워크 설정에서 IP 주소 할당을 확인해 보아야 합니다. 설정 메뉴의 네트워크 상세 정보 페이지에서 IP 주소와 게이트웨이 정보가 정상적으로 표시되는지 체크합니다. 만약 정보가 표시되지 않는다면 공유기를 재부팅하거나 다시 연결을 시도하는 것이 좋습니다. 연결 상태가 양호하면 화면 우측 상단에 와이파이 아이콘이 활성화되어 있음을 알 수 있습니다.
