공용 와이파이나 타인의 네트워크에 연결할 때 사용자의 기록이 어디까지 남는지 궁금해하는 분들이 많습니다. 결론부터 말씀드리면, 와이파이 관리자는 접속 기기의 맥 주소와 데이터 사용량 정도를 확인할 수 있습니다. 하지만 어떤 사이트를 방문했는지, 대화 내용은 무엇인지 등의 상세한 개인 정보까지는 일반적인 관리자 수준에서 열람하기 어렵습니다.

## 관리자가 확인 가능한 정보의 범위

와이파이 공유기 관리자는 접속한 기기의 고유 식별 번호인 맥 주소를 볼 수 있습니다. 또한 해당 기기가 언제 접속하여 얼마나 많은 데이터를 사용했는지에 대한 트래픽 통계도 확인 가능합니다. 하지만 방문한 웹사이트의 구체적인 내용이나 입력한 비밀번호까지는 일반적인 관리자 모드에서 보이지 않습니다. 대부분의 웹사이트는 HTTPS 암호화 프로토콜을 사용하기 때문입니다. 따라서 기본적인 웹 서핑 시 개인적인 데이터 노출은 크게 우려하지 않아도 됩니다.

## HTTPS 암호화와 데이터 보호

현재 대부분의 웹사이트 주소는 HTTPS로 시작하며 이는 통신 데이터를 암호화합니다. 암호화된 상태에서는 데이터가 중간에 가로채지더라도 내용을 해독할 수 없습니다. 따라서 공유기 관리자가 패킷을 분석하더라도 사용자가 어떤 정보를 주고받는지 알기 어렵습니다. 다만 사이트의 도메인 주소 정도는 관리자가 로그를 통해 확인할 가능성이 있습니다. 보안을 강화하고 싶다면 공용 와이파이 사용 시 VPN을 활용하는 것이 좋습니다.

## 공용 와이파이 사용 시 보안 위협

공용 와이파이의 진짜 위험은 관리자의 기록보다는 해커의 중간자 공격입니다. 동일한 네트워크에 접속한 해커가 사용자의 데이터를 가로채는 방식이 존재합니다. 보안이 취약한 공용 와이파이에서는 금융 거래나 개인 정보 입력은 피하는 것이 좋습니다. 반드시 사용해야 한다면 VPN을 켜서 통신 경로를 안전하게 보호하십시오. 보안이 설정되지 않은 개방형 와이파이는 가급적 이용하지 않는 것이 가장 현명합니다.

## 내 기록을 지우는 방법

공유기에 남은 접속 기록은 사용자가 직접 삭제할 수 없습니다. 공유기 관리자가 로그를 삭제하지 않는 한 접속 기록은 일정 기간 서버에 남게 됩니다. 만약 개인적인 보안이 걱정된다면 해당 와이파이의 저장된 네트워크를 삭제하는 것으로 충분합니다. 기기 설정에서 와이파이 목록을 찾아 네트워크를 잊어버리면 됩니다. 이후에는 해당 공유기에 자동으로 재연결되지 않으므로 안심할 수 있습니다.

## 개인 기기에서 확인 가능한 연결 이력

스마트폰이나 노트북 설정에서 이전에 연결했던 와이파이 목록을 확인할 수 있습니다. 사용자는 언제든 이 목록을 관리하거나 삭제할 수 있는 권한이 있습니다. 만약 의심스러운 와이파이에 연결된 적이 있다면 즉시 목록에서 삭제하십시오. 불필요한 자동 연결을 막는 것만으로도 보안 사고를 예방할 수 있습니다. 개인 기기의 보안 설정은 주기적으로 점검하는 습관이 중요합니다.

## 보안을 위한 올바른 네트워크 습관

가장 안전한 방법은 공용 와이파이 대신 본인의 데이터를 사용하는 것입니다. 데이터 사용이 부담된다면 보안이 검증된 와이파이만 선별적으로 사용하십시오. 비밀번호가 없는 와이파이는 해킹의 표적이 되기 쉬우므로 주의가 필요합니다. 기기의 소프트웨어를 항상 최신 상태로 업데이트하여 보안 취약점을 방지하십시오. 작은 보안 습관이 큰 정보 유출을 막는 가장 효과적인 방법입니다.

와이파이 관리자는 사용자의 기기 정보와 데이터 사용량 정도만 알 수 있을 뿐 상세 내용은 확인하기 어렵습니다. 다만 공용 네트워크는 보안상 취약할 수 있으니 항상 주의가 필요합니다. 안전한 디지털 생활을 위해 위 수칙들을 참고하시길 바랍니다.
