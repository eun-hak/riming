아이폰의 기본 브라우저를 사파리에서 크롬으로 변경하면 링크를 클릭할 때마다 크롬이 자동으로 실행됩니다. iOS 14 버전 이후부터는 사용자가 선호하는 웹 브라우저를 기본값으로 지정할 수 있도록 기능이 제공됩니다. 설정 과정을 통해 아이폰의 활용도를 높이고 본인에게 익숙한 환경을 조성할 수 있습니다. 크롬 브라우저를 기본으로 설정하는 간단한 단계를 안내해 드립니다.

## 크롬 앱 설치 및 최신 버전 확인

기본 브라우저 설정을 위해서는 먼저 앱스토어에서 크롬 앱이 설치되어 있어야 합니다. 이미 설치되어 있다면 앱이 최신 버전인지 확인하십시오. 구버전에서는 기본 브라우저 설정 옵션이 나타나지 않을 수 있습니다. 앱스토어에서 업데이트 버튼을 눌러 최신 상태를 유지하는 것이 중요합니다. 설치가 완료되었다면 다음 단계로 진행할 수 있습니다.

## 아이폰 설정 앱에서 크롬 찾기

아이폰의 기본 설정 앱을 열고 아래로 스크롤하여 앱 목록을 확인합니다. 설치된 앱들 사이에서 크롬 아이콘을 찾아 선택하십시오. 크롬 관련 설정을 변경할 수 있는 상세 페이지가 나타납니다. 여기서 브라우저와 관련된 다양한 옵션을 조정할 수 있습니다. 이 메뉴는 각 앱의 고유한 설정을 관리하는 곳입니다.

## 기본 브라우저 앱 항목 선택

크롬 설정 페이지 내에 기본 브라우저 앱이라는 메뉴가 있습니다. 이 항목을 누르면 현재 설정된 브라우저 목록을 볼 수 있습니다. 사파리가 기본값으로 되어 있다면 크롬을 선택하여 변경해 주십시오. 선택 즉시 기본 브라우저가 크롬으로 변경됩니다. 이제 웹 링크를 누르면 사파리 대신 크롬이 열리게 됩니다.

## 설정 변경이 보이지 않는 경우

만약 기본 브라우저 앱 메뉴가 보이지 않는다면 iOS 버전이 낮을 가능성이 큽니다. 아이폰의 설정, 일반, 소프트웨어 업데이트를 통해 최신 운영체제로 업데이트하십시오. 또한 크롬 앱을 삭제 후 재설치하는 것도 좋은 방법입니다. 재설치 후에는 기본 브라우저 설정 옵션이 정상적으로 노출될 것입니다. 기기 재부팅을 함께 진행하면 시스템 반영이 빨라집니다.

## 다른 브라우저로 다시 변경하기

크롬을 사용하다가 다시 사파리나 다른 브라우저로 돌아가고 싶을 때도 동일한 경로를 이용합니다. 각 브라우저의 설정 메뉴로 들어가서 기본 브라우저 앱 항목을 찾으면 됩니다. 언제든지 사용자가 원하는 환경으로 쉽게 변경할 수 있습니다. 아이폰은 여러 브라우저를 설치해두고 상황에 따라 기본값을 바꿀 수 있습니다. 본인에게 가장 편리한 도구를 선택하십시오.

## 웹 링크 실행 테스트

설정을 마친 후에는 정상적으로 작동하는지 확인해야 합니다. 메시지나 메모 앱에 있는 웹사이트 링크를 하나 클릭해 보십시오. 크롬이 자동으로 실행되면서 해당 페이지가 열린다면 성공입니다. 만약 사파리가 계속 열린다면 설정을 다시 확인해야 합니다. 설정 변경이 제대로 저장되지 않았을 수 있으니 앱을 완전히 종료 후 다시 시도하십시오.

아이폰의 기본 브라우저를 크롬으로 설정하는 것은 설정 앱 내의 간단한 조작으로 가능합니다. iOS 최신 버전을 유지하여 원활한 브라우저 전환 기능을 활용하시기 바랍니다.
