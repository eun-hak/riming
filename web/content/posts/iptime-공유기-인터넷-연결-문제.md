IPTIME 공유기를 새로 설치했는데 인터넷이 연결되지 않는다면 대부분 설정 오류나 회선 문제일 가능성이 큽니다. 모뎀과 공유기의 연결 상태를 확인하고 관리자 페이지에서 인터넷 설정을 점검해야 합니다. 문제를 해결하기 위한 구체적인 단계를 안내합니다.

## 물리적 케이블 연결 상태 확인하기

가장 먼저 모뎀에서 나온 인터넷 선이 공유기의 WAN 포트에 제대로 꽂혔는지 확인하십시오. WAN 포트는 보통 다른 색상으로 구분되어 있습니다. 컴퓨터와 연결된 LAN 케이블은 1번부터 4번 포트 중 하나에 연결되어야 합니다. 케이블이 헐겁게 꽂혀 있으면 신호가 불안정할 수 있으니 꽉 눌러서 확인하십시오. 모뎀의 전원과 공유기의 전원이 모두 켜져 있는지 확인하는 것도 기본입니다. 물리적인 연결만 제대로 되어도 대부분의 문제가 해결됩니다. 선을 뽑았다가 다시 정확하게 꽂아보며 반응을 살펴보십시오.

## 모뎀과 공유기 재부팅으로 신호 초기화

공유기를 설치한 직후에는 모뎀과 공유기의 신호가 동기화되지 않을 수 있습니다. 모뎀의 전원을 끄고 1분 정도 기다린 뒤 다시 켜주십시오. 모뎀이 완전히 부팅된 후 공유기의 전원을 켜는 순서가 중요합니다. 이렇게 하면 통신사에서 할당하는 IP 주소를 공유기가 정확히 받아올 수 있습니다. 간단한 재부팅만으로도 연결 오류를 해결하는 경우가 많습니다. 공유기 상태 표시등이 정상적으로 깜빡이는지 확인하십시오. 신호가 잡히지 않는다면 다시 한번 부팅 순서를 지켜 시도해 보십시오.

## 공유기 관리자 페이지 접속 및 설정

웹 브라우저를 열고 주소창에 192.168.0.1을 입력하여 관리자 페이지에 접속하십시오. 로그인 후 인터넷 설정 정보 메뉴에서 현재 연결 상태를 확인하십시오. 외부 IP 주소가 0.0.0.0으로 표시된다면 인터넷 신호를 받지 못하고 있는 것입니다. 이 경우 인터넷 연결 설정 마법사를 실행하여 자동 설정을 시도하십시오. 통신사에서 특정 인증을 요구하는 환경이라면 해당 설정을 수동으로 입력해야 합니다. 관리자 페이지는 공유기의 상태를 파악하는 가장 정확한 도구입니다. 설정 값을 변경한 후 반드시 적용 버튼을 누르십시오.

## 통신사 모뎀의 맥 어드레스 인증 문제

일부 통신사는 특정 기기의 맥 어드레스만 허용하는 경우가 있습니다. 모뎀에 직접 PC를 연결했을 때는 인터넷이 되는데 공유기를 거치면 안 되는 상황입니다. 이때는 관리자 페이지에서 맥 주소 변경 기능을 사용해 보십시오. 기존에 인터넷이 되던 PC의 맥 주소를 공유기에 복사하는 방식입니다. 이렇게 하면 통신사에서 공유기를 기존 PC로 인식하여 인터넷을 허용합니다. 기술적인 설정이 필요하지만 이 방법으로 대부분 해결됩니다. 통신사 고객센터에 전화하여 기기 변경 등록을 요청하는 것도 하나의 방법입니다.

## 공유기 펌웨어 업데이트 수행하기

공유기의 펌웨어가 너무 구버전이면 최신 통신 환경과 호환되지 않을 수 있습니다. 관리자 페이지의 관리 도구 메뉴에서 펌웨어 업그레이드 항목을 선택하십시오. 최신 펌웨어를 자동으로 검색하고 설치하는 기능을 활용하십시오. 업데이트 중에는 절대 전원을 끄지 않도록 주의해야 합니다. 펌웨어 개선을 통해 연결 안정성이 크게 향상될 수 있습니다. 설치 직후 연결이 불안정하다면 펌웨어를 최신으로 유지하는 것이 필수입니다. 업데이트가 완료되면 공유기가 재부팅되면서 신호를 다시 잡습니다.

## IP 충돌 확인 및 내부 네트워크 점검

내부 네트워크의 IP 주소가 충돌하면 인터넷 연결이 원활하지 않습니다. 관리자 페이지에서 내부 네트워크 설정 메뉴를 확인하십시오. 다른 기기와 IP 주소가 겹치지 않는지 점검하고 필요시 IP 주소 대역을 변경하십시오. 연결된 기기가 너무 많다면 DHCP 할당 범위를 조정해야 할 수도 있습니다. 공유기의 초기화 버튼을 길게 눌러 공장 초기화 상태로 돌리는 것도 방법입니다. 처음부터 설정을 다시 시작하면 복잡한 오류를 한 번에 해결할 수 있습니다. 네트워크 환경을 단순하게 구성하여 문제를 좁혀가십시오.

## 최후의 수단으로 공장 초기화 진행

모든 방법을 시도해도 해결되지 않는다면 공유기를 공장 초기화하십시오. 공유기 뒷면의 작은 구멍에 핀을 넣어 10초 정도 누르면 초기화됩니다. 초기화 후에는 관리자 페이지에 다시 접속하여 설정을 처음부터 진행해야 합니다. 비밀번호 설정부터 인터넷 연결까지 다시 세팅하십시오. 초기화는 공유기의 모든 설정을 삭제하므로 마지막 단계에서 신중하게 결정하십시오. 이제까지의 오류가 설정 꼬임 때문이었다면 초기화 후 해결될 것입니다. 초기화 후에도 안 된다면 공유기 자체의 고장 가능성을 의심해 보십시오.

연결 문제가 지속되면 케이블 상태와 모뎀 부팅 순서를 우선 확인하십시오. 관리자 페이지 설정을 통해 대부분의 통신 오류를 해결할 수 있습니다.
