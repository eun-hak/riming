PC 와이파이 연결은 랜선 없이 무선 공유기의 신호를 잡아 인터넷을 사용할 수 있게 만드는 설정 과정입니다. 노트북은 무선 랜카드가 내장되어 있어 쉽게 연결되지만 데스크탑은 무선 랜카드가 없으면 추가 장치가 필요합니다. 본문에서는 윈도우 운영체제에서 무선 네트워크를 잡는 순서와 랜카드 종류, 연결 오류 해결법을 다루겠습니다. 공유기 비밀번호나 네트워크 이름 확인이 선행되어야 합니다.

## 노트북에서 와이파이 네트워크 잡는 순서

작업표시줄 우측 하단의 지구본 모양이나 와이파이 아이콘을 클릭하여 주변 네트워크 목록을 엽니다. 사용할 무선 공유기 이름을 선택하고 연결 버튼을 누른 뒤 보안 키를 입력합니다. 자동으로 연결되도록 설정해 두면 부팅 시 번거로운 과정 없이 바로 인터넷에 접속됩니다. 비행기 모드가 켜져 있으면 와이파이 신호가 잡히지 않으므로 상태를 먼저 확인합니다.

## 데스크탑에 무선 랜카드가 필요한 이유

일반적인 데스크탑 본체에는 유선 랜 포트만 장착되어 있어 와이파이 신호를 수신할 수 없습니다. USB형 무선 랜카드를 포트에 꽂거나 PCI-e 슬롯형 무선 랜카드를 메인보드에 장착해야 합니다. 랜카드를 설치한 후 제조사의 드라이버를 깔아야 정상적으로 무선 네트워크 목록이 뜹니다. 기가 인터넷을 안정적으로 쓰려면 와이파이 규격이 높은 랜카드를 선택하는 것이 유리합니다.

## 와이파이 비밀번호 확인 및 입력 오류 해결

공유기 하단에 적힌 기본 SSID와 암호를 확인하거나 스마트폰으로 공유기 설정 페이지에 접속해 확인합니다. 대소문자와 특수문자를 정확하게 입력했음에도 연결이 안 되면 공유기를 재부팅해 봅니다. 다른 기기는 잘 연결되는데 특정 PC만 안 된다면 네트워크 어댑터 사용 안 함 후 다시 사용으로 바꿉니다. IP 주소 충돌이 발생한 경우 명령 프롬프트에서 설정을 초기화합니다.

## 무선 네트워크 어댑터 드라이버 업데이트

인터넷이 끊기거나 속도가 지나치게 느릴 때는 무선 랜카드 드라이버가 최신 버전인지 확인합니다. 장치관리자에서 네트워크 어댑터 항목을 열고 해당 랜카드를 우클릭하여 드라이버 업데이트를 진행합니다. 제조사 홈페이지에서 최신 드라이버를 직접 다운로드하여 설치하는 것이 가장 확실합니다. 윈도우 업데이트 과정에서 드라이버 충돌이 생길 수 있으니 주기적으로 점검합니다.

## 신호 약함 및 인터넷 끊김 현상 대처법

공유기와 PC 사이의 거리가 멀거나 벽 등의 장애물이 많으면 무선 신호가 약해져 자주 끊깁니다. 공유기의 위치를 개방된 곳으로 옮기거나 와이파이 확장기를 설치하여 음영 지역을 해소합니다. 2.4GHz와 5GHz 대역 중 공유기와 가까울 때는 속도가 빠른 5GHz를 선택하고 거리가 멀면 2.4GHz를 씁니다. 주변의 다른 무선 기기와 주파수 간섭이 일어나는지 채널을 변경해 봅니다.

## 숨겨진 네트워크 수동 연결 및 설정 방법

보안을 위해 SSID를 숨겨둔 공유기는 목록에 나타나지 않으므로 수동으로 추가해야 합니다. 네트워크 및 인터넷 설정에서 수동으로 네트워크 추가를 선택하고 이름과 보안 유형을 입력합니다. 정확한 암호를 알고 있어야만 접속이 가능하며 기업이나 공공기관에서 주로 사용합니다. 입력한 정보가 하나라도 틀리면 연결에 실패하므로 관리자에게 정확한 값을 문의합니다.

PC 와이파이 연결은 랜카드 장착과 드라이버 설치, 정확한 암호 입력으로 원활하게 해결할 수 있습니다. 신호가 불안정하다면 공유기 위치와 주파수 대역을 점검해 보시기 바랍니다.
