인터넷 설치 없이 와이파이만으로 컴퓨터를 사용하려는 경우 스마트폰의 테더링 기능을 활용하는 것이 대표적인 방법입니다. 통신사의 데이터 요금제를 이용해 와이파이 신호를 생성하고 이를 노트북이나 PC에서 수신할 수 있습니다. 별도의 유선 인터넷 계약 없이도 긴급하게 인터넷을 연결해야 할 때 매우 유용합니다. 지금부터 테더링 설정법과 주의사항을 알기 쉽게 설명해 드리겠습니다.

## 스마트폰 테더링 기능의 원리

테더링은 스마트폰이 수신하는 LTE나 5G 신호를 주변 기기가 사용할 수 있도록 와이파이 신호로 변환해 주는 기능입니다. 이를 통해 유선 인터넷 연결이 없는 환경에서도 노트북으로 웹 서핑이나 문서 작업이 가능합니다. 스마트폰의 설정 메뉴에서 핫스팟 기능을 켜기만 하면 됩니다. 사용 중인 요금제의 데이터 한도를 미리 확인하는 것이 중요합니다.

## 컴퓨터에서 테더링 연결하는 방법

스마트폰에서 핫스팟을 활성화했다면 컴퓨터의 무선 네트워크 목록을 확인하십시오. 설정한 와이파이 이름(SSID)을 선택하고 비밀번호를 입력하면 연결이 완료됩니다. 윈도우 설정의 네트워크 메뉴에서 해당 와이파이를 신뢰할 수 있는 네트워크로 지정하십시오. 연결이 잘 되지 않는다면 스마트폰의 핫스팟 밴드를 2.4GHz로 변경하여 호환성을 높일 수 있습니다.

## 데이터 사용량 확인과 요금제 점검

테더링은 많은 데이터를 소모하므로 무제한 요금제 사용자가 아니라면 주의가 필요합니다. 동영상을 시청하거나 대용량 파일을 다운로드하면 데이터가 빠르게 소진됩니다. 스마트폰의 데이터 사용량 알림 기능을 켜서 초과 요금이 발생하지 않도록 관리하십시오. 통신사 앱을 통해 현재 남은 테더링 전용 데이터 양을 주기적으로 체크하는 습관이 중요합니다.

## USB 테더링을 이용한 안정적인 연결

와이파이 신호가 불안정하다면 USB 케이블을 이용한 테더링을 추천합니다. 스마트폰과 컴퓨터를 USB 케이블로 연결한 뒤 설정에서 USB 테더링을 활성화하면 훨씬 안정적인 속도로 인터넷을 즐길 수 있습니다. 무선 방식보다 발열이 적고 끊김 현상이 거의 없습니다. 고사양 작업이나 화상 회의를 진행해야 할 때 유용한 방식입니다.

## 테더링 사용 시 보안 유지 수칙

핫스팟을 켤 때는 반드시 강력한 비밀번호를 설정해야 합니다. 비밀번호가 없으면 주변의 타인이 무단으로 데이터를 사용하여 요금 폭탄을 맞을 수 있습니다. 공공장소에서 사용할 때는 더욱 보안 설정에 신경 써야 하며 사용이 끝난 후에는 반드시 핫스팟을 끄는 것이 좋습니다.

## 와이파이 에그나 라우터의 대안

테더링이 불편하다면 휴대용 와이파이 공유기인 에그(Egg)를 고려해 볼 수 있습니다. 별도의 통신사 유심을 꽂아 사용하는 라우터는 테더링보다 훨씬 쾌적한 인터넷 환경을 제공합니다. 장기적으로 인터넷 설치가 어려운 환경에 거주한다면 에그 구매가 경제적일 수 있습니다. 통신사의 다양한 무선 라우터 상품을 비교하여 본인의 사용량에 맞는 요금제를 선택하십시오.

스마트폰 테더링은 인터넷 설치 없이 컴퓨터를 연결할 수 있는 효율적인 수단입니다. 데이터 요금제 한도를 확인하고 보안 설정을 철저히 하여 안전하게 사용하시기 바랍니다.
